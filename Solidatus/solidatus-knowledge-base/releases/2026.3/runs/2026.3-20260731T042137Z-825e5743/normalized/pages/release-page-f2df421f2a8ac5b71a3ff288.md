# Top navigation bar

The Navigation Bar sits at the top of the user interface through all areas of the platform and enables you to move between functions and features.

## Navigate Solidatus

While there are often multiple ways to get from one area of the platform to another, the Navigation Bar offers one of those ways.

<figure><figcaption><p>The Navigation Bar in the Model Browser, Groups Manager and My Activities</p></figcaption></figure>

{% hint style="success" %}
While Search and Dashboards are still available in Solidatus 6.4, they will be replaced by the cross-model search and Analytics Reports features in Data Domains.
{% endhint %}

If you click <mark style="color:red;">`Solidatus`</mark> or the Solidatus logo on the left-hand side of the Navigation Bar from anywhere in the platform, you will be taken back to the [Model Browser](/the-user-interface/models-ui/model-browser).

You can click the headings in the Navigation Bar to access the Data Domains and Models areas in Solidatus. You can also access your Groups, Activities, and the Connectors interface for managing, configuring, and running connectors.

On the right-hand side of the Navigation Bar, you can access notifications, user account settings, this platform documentation, and other policy and legal statements.

If you are an administrator, you will see the additional <mark style="color:red;">`ADMIN`</mark> button listed to the right of <mark style="color:red;">`DOMAINS`</mark> in the Navigation Bar, which will take you to the Admin area where you can monitor and manage your instance.

{% hint style="success" %}
The [Connectors](/connectors/connectors-overview) option is visible to every user registered to your instance if the feature is enabled.
{% endhint %}

## Navigation bar in the Model Viewer & Lineage Explorer

When in the [Model Viewer](/the-user-interface/models-ui/model-viewer) and [Lineage Explorer](/models/explore-and-analyse-models/lineage-explorer), the Navigation Bar buttons are different from other areas of the platform.

In these model viewing modes, the Navigation Bar shows the status of unsaved changes, the views currently applied to the model, and the name of the model.

You can easily navigate to the Model Overview of the model you are viewing by clicking the model name in the Navigation Bar. You can also return to the Model Browser by clicking <mark style="color:red;">`HOME`</mark> or <mark style="color:red;">`Solidatus`</mark> on the left-hand side, and you can open the model in the [Graph Explorer](/models/explore-and-analyse-models/graph-explorer) by clicking <mark style="color:red;">`GRAPH`</mark>.

## Notification settings

You will get notifications on the Navigation Bar and/or by email for a number of different events, such as when a new Model has been published in a group you are a member of.

Click on the bell symbol on the Navigation Bar to access your notifications. A red number next to the bell tells you how many unread notifications you have.

Click on a Notification to open the affected Model or Activity.

You can change your Notification preferences in the [Account Settings](/account-management/account-settings). You can choose to receive notifications via the app and/or email for the following events:

**General users**

* Group invitation received
* Model is published to group
* Model is forked
* Pull request received
* Parent model is updated
* Model imports have updates

**Activities**

* New task received
* Task has activity
* Task is published to group
* Model is shared with you
* Task is shared with you
* An activity you’re contributing to has been merged

**Approvals**

* Status of approval to share model to group has changed
* You have been assigned to review a new activity
* Your review in an activity has been overridden by a new revision
* Approval or rejection for an activity has been revoked
* Activity has been closed or reopened
* An activity has been approved
* Changes have been requested on an activity you’re assigned to
* Automerge has failed
* Automerge has been skipped

There are additional notifications for Administrators.

## Getting more information and help

The dropdown menu at the right-hand end of the Navigation Bar provides access to several sources of information (opens in a new tab).

* The built-in documentation
* Information about the features of the current screen (selected screens only)
* Send us feedback via email
* View the End User Licence Agreement (EULA)
* View the Solidatus Privacy Policy
* View acknowledgements for the third-party software that is included
