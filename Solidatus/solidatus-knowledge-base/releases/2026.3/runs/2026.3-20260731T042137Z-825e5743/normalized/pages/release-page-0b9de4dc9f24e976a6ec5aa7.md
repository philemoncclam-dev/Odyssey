# Explore and analyse models

Many people using Solidatus will spend their time browsing, exploring, and analysing models that have already been created and updated by others.

Models are analytical tools that help you understand the data landscapes they represent. These pages are meant to cover model functionality intended to help you get the information you need from an existing model.

Analysing a model can take several forms:

* Navigating a model and finding content
* Querying a model to find things that meet specific criteria
* Creating Filters and Display Rules to highlight information
* Creating Views to draw attention to specific content that answers questions
* Exporting model data and metadata to reuse in external tools
* Viewing a model as a text document, a graph, or through the lineage explorer
