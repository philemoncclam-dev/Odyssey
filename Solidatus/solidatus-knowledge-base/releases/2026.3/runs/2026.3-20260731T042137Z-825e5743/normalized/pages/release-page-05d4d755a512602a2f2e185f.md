# User interface layout

The Solidatus user-interface is divided into four main functional areas in which the core capabilities of the platform can be found and used.

<table data-header-hidden><thead><tr><th width="298"></th><th></th></tr></thead><tbody><tr><td><strong>Areas of the User Interface</strong></td><td><strong>Core capabilities and functions</strong></td></tr><tr><td><a href="/pages/oLOFXUFzTd6ePONjdFF8">Models interface</a></td><td>Viewing, building, editing, analysing, and sharing models that represent your data and reference landscapes.</td></tr><tr><td><a href="/pages/MyxZsatOLvAdmiw9IGaq">Data Domains interface</a></td><td>Building, searching, and browsing Data Domains, viewing Data Maps, and using <a href="/pages/2mjSOaqPuNcdACPayemR">Analytics Reports</a>.</td></tr><tr><td><a href="/pages/yS889JT7HdsyKnlBpodc">Connectors interface</a></td><td>Configuring, managing, and executing Connector Agents and Jobs to ingest metadata into Solidatus models.</td></tr><tr><td><a href="/pages/pPloP3e2oQVHE0jTg1jj">Activities interface</a></td><td>Viewing, managing, and configuring model <a href="/pages/L580ZsFWX7PX4K6uvqix">activities</a> and the <a href="/pages/voBIBidk8fpzPiAT6XnP">approvals workflow</a> to collaborate on model building.</td></tr></tbody></table>

All four functional areas can be accessed in one click through the [top navigation bar](/the-user-interface/the-navigation-bar), which sits at the top of the Solidatus interface throughout all areas of the platform.

<figure><figcaption><p>The Navigation Bar</p></figcaption></figure>

The top navigation bar gets you from one functional area to another, and the right-hand side provides access to notifications, account settings, this help documentation, and other policy and legal documents.

See [top navigation bar](/the-user-interface/the-navigation-bar) page for more detailed information on functions accessible through the bar.
