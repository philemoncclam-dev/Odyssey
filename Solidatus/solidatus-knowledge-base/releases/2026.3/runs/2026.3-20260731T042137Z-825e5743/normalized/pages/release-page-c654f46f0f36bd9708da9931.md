# Model Viewer Sidebar

The sidebar is a set of menus on the right-hand side of the Model Viewer and Lineage Explorer that contains various tools for using, navigating, and editing Solidatus models. A modified version of the sidebar is included in the Graph Explorer.

The sidebar is made up of four separate tabs with context-sensitive content. Each tab can be opened and closed by clicking the name on the sidebar at the right-hand side of the screen. If a tab is already open, clicking a new tab will replace the currently open one.

Follow the links below to learn more about the actions available in each sidebar tab.

## Customise the sidebar

The details below apply to the Model Viewer sidebar, but the sidebar in the Lineage Explorer works in the same way and has similar content.

The sidebar has two alternative layouts: the *classic layout* and the *new layout*. You can switch between the two layouts by clicking on the vertical ellipsis `...` (three dots dropdown) at the bottom of the sidebar.

### Hide or show sidebar panels

At the top of the sidebar, to the left of the name of the currently open tab, is a three-dot dropdown that allows you to choose which panels are visible in the currently open tab. The list does not include any sections that have been detached from the tab.

<figure><figcaption><p>How to change which sections are visible</p></figcaption></figure>

{% hint style="success" %}
Changes to the order or visibility of sidebar panels will be stored and will carry over to other models automatically, even if you do not save the model you have customised. To revert to the default sidebar settings, see [Reset the Sidebar Panels](#reset-the-sidebar-panels).
{% endhint %}

### Change the order of sidebar panels

Panels can be collapsed and expanded by clicking the chevron in the panel’s header.

You can move panels into a different order by clicking panel headers and dragging them to another position.

There is also a three-dots dropdown menu at the right-hand side of each panel’s header that can be used to move or detach the panel.

<figure><figcaption><p>How to re-order sections</p></figcaption></figure>

### Detach sidebar panels

{% hint style="success" %}
Detaching a section allows it to be placed anywhere within the user interface. The section can be returned to the sidebar by pressing the <mark style="color:red;">x</mark> button at the top right-hand corner of the detached section.
{% endhint %}

### **Drag panels away from the sidebar**

You can drag sections away from the Sidebar, placing them wherever you would prefer to see them, alongside each other to focus on a task, or perhaps alongside the entities you’re working on in the Model Viewer.

In the image below, two sections have been dragged from the [The Reference Models Tab](/the-user-interface/models-ui/model-viewer/model-viewer-sidebar/the-reference-models-tab) so that they are next to the `Properties and Relationships` panel in [The Inspector Tab](/the-user-interface/models-ui/model-viewer/model-viewer-sidebar/the-inspector-tab).

### Reset the sidebar panels

If you have detached any of the sidebar panels or rearranged their order, resetting to the new or classic layouts will cause them to be reattached to the sidebar in the default order.
