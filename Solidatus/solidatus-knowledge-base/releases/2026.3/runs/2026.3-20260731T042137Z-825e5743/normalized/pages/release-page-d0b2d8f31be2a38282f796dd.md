# Keyboard and mouse shortcuts

Keyboard shortcuts are keys or combinations of keys that provide an alternative way to do something in the Solidatus Model Viewer. Where a shortcut includes one or more `+` signs, you need to press and hold several keys simultaneously.

Mouse shortcuts require you to click a mouse button, and possibly also press a key on the keyboard.

{% hint style="success" %}
Multiple entries indicate alternative shortcuts for the same action.
{% endhint %}

We’ve grouped our shortcuts into four categories to help you find the one you want.

## Navigating and selecting

| Navigate among entities               | Select an entity, then use the Arrow keys                                                                                                                              |
| ------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Select range of entities              | <p><strong>Shift</strong> + Arrow keys</p><p><strong>Shift</strong> + <strong>Ctrl</strong> + Arrow keys</p><p><strong>Shift</strong> + <em>click left button</em></p> |
| Add to selection                      | **Ctrl** + *click left button*                                                                                                                                         |
| Collapse/Expand all selected entities | **Space**                                                                                                                                                              |
