# Data Domains main

**Data Domains** transform technical models into business-friendly and business-facing portals for data discovery, data governance, quantitative reports, and end-to-end lineage analysis.

A Data Domain is a portal for searching, browsing, querying, exploring lineage, and quantitatively analysing *across multiple models*. Each domain publishes content and builds cross-model lineage from the set of models you choose to include.

Each Data Domain includes an integrated **Data Map** — a specialised lineage exploration and visualisation tool that automatically aggregates lineage across published models and presents fine-grained, technical data flows in high-level, business-friendly visual summaries.

***

Key benefits of Data Domains:

* **Familiar search portal experience across multiple models**: Find and analyse data and infrastructure using an interface as intuitive as web search or file browsing
* **Business-friendly discovery**: Make technical systems discoverable and understandable through widely recognised and familiar business terms
* **Cross-model lineage**: Use Data Maps to visualise end-to-end data flows across multiple models with business context
* **Quantitative insights**: Generate Analytics reports for data-driven analysis of your lineage and governance landscape
