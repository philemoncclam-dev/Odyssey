## Webhook Notifications (beta)

Webhooks can issue notifications to external apps to keep track of model events. But they can also make Solidatus a central part of an automated workflow of discrete, connected systems.

With webhooks enabled, any time a model is updated or metadata is changed, Solidatus can automatically call the API of another system.

See [Webhooks](/api-documentation/webhooks) for more info.

{% hint style="info" %}
This is a *Beta* feature and so is still in development. The feature will only be available if it has been switched on in your Solidatus configuration.

All feedback on current and potential capabilities is very welcome - please contact [support@solidatus.com](mailto:support%40solidatus.com).
{% endhint %}
