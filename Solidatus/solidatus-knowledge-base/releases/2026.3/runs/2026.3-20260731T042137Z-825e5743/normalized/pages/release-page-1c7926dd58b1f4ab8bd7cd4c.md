# Domain page interface

<figure><figcaption></figcaption></figure>

1. Breadcrumbs showing the path of the entry in the structure of the domain. Click an item to open it in the main window.
2. The name of the entry and the intials of owners of the original model in which it resides.
3. Breadcrumbs showing the path of the entry in its original model. Click an item to go to its Entry Page in the Data Domain.
4. Navigate the tabs on an Entry Page to analyse a domain entry.
5. Click to view the entry in the original model with a focused trace applied to highlight its lineage.

{% hint style="success" %}
The four tabs on an Entry Page are different for lineage entities and reference terms.
{% endhint %}

For lineage entities, you will find the `Overview`, `Sub-entities`, `Lineage`, and `History` tabs.

<figure><figcaption></figcaption></figure>

For Reference terms, you will find the `Overview`, `Sub-terms`, `Related Entities`, and `History` tabs.

<figure><figcaption></figcaption></figure>

For details of information contained on a Entry Page and tips on how to examine one, visit [Examine a Domain Entry](/data-domains/explore-data-domains/examine-an-entry-page).
