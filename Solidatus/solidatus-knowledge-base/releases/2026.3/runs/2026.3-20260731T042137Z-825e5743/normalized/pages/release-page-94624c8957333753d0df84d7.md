# AzureSQL

AzureSQL is a cloud managed distribution of Microsoft SQL Server. The JDBC connector can connect to an AzureSQL database to pull structure and lineage metadata. To leverage these capabilities, `solidatus.jdbc.driver` must be set to `azuresql`. For SQL parsing related features `solidatus.jdbc.dialect` must be set to `azuresql`.

## **Supported Features Overview**

|   **Feature**   | **Included** | **Coverage**                                                                                                                                        |
| :-------------: | :----------: | --------------------------------------------------------------------------------------------------------------------------------------------------- |
|    Structure    |       ✓      | Database structure                                                                                                                                  |
|     Lineage     |       ✓      | SQL Parsing from scripts, stored procedures and data dictionary metadata to visualise the flow of data between database objects at the column level |
| SQL Derivations |       ✓      | Source code for Table level derivations and Column level derivations                                                                                |
