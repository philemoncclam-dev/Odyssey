# Collibra

The Solidatus Connector for Collibra allows importing organisation data from Collibra to Solidatus as well as exporting model data from Solidatus to Collibra. The connector enables modelling and exploration of data flows with the powerful Solidatus tools, as well as integration with lineage from other sources once inside Solidatus.

### Importing (Collibra -> Solidatus) <a href="#importing-collibra-greater-than-solidatus" id="importing-collibra-greater-than-solidatus"></a>

#### **Supported Features Overview** <a href="#supported-features-overview" id="supported-features-overview"></a>

| **Feature**        | **Included** | **Example**                                                                                                   |
| ------------------ | ------------ | ------------------------------------------------------------------------------------------------------------- |
| Metadata Structure | ✓            | Collibra Community structure, Collibra Domain structure, Collibra Asset hierarchy based on Collibra Relations |
| Lineage            | ✓            | Collibra Asset lineage based on Collibra Relations                                                            |
