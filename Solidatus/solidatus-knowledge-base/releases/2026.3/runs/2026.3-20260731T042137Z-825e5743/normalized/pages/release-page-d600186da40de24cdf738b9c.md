# Models API reference

The API for interacting with models is extensive. It includes several endpoints and methods for retrieving, creating, and updating model content and associated metadata.

Note that a comprehensive reference that lists all API endpoints, methods, and schemas can be found on our Swagger site, which can be accessed via the Help section inside Solidatus (you need to be logged in to access this documentation).
