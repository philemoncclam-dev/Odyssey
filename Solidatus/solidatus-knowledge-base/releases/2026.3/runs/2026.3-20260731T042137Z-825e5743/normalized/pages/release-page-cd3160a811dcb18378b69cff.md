# Solidatus 2026.2

Solidatus 2026.2 introduces a set of performance improvements and usability enhancements designed to make working with large models faster, smoother, and more intuitive.

* Work more efficiently in the Model Viewer
* Improved Model Browser experience
* Return to Data Map views exactly as you left them
* Create and manage more powerful display rules
* Query domains with greater precision
* Reduce noise in search and metrics with duplicate control

Solidatus 2026.2 continues to improve everyday workflows while maintaining clarity, control, and governance across your models.

Read on to find out what else is in Solidatus 2026.2.

### New features

**Enhanced Data Map views**

Data Map views now retain more of your working state, allowing you to return to a view exactly as you left it. This includes:

* Active tags
* Expanded and collapsed entities
* Applied context
* Trace settings

A new “Save as” option allows you to create a new view from an existing one, making it easier to reuse and build on previous analysis.

**New Data Map display rules**

Display rules have been expanded to provide more precise control over how entities are highlighted in a Data Map. You can now:

* Tag entities based on property values
* Use relationship labels as conditions
* Match against related reference terms, including names and properties

Menus are pre-populated with values already present in the domain, making rule creation faster and more intuitive.

**Modules for Data Map display rules**

Display rules can now be grouped into modules, making it easier to manage complex rule sets. Modules allow you to:

* Organise rules at scale
* Enable or disable groups of rules in a single action
* Filter to show only active rules

This improves visibility and control when working with multiple layers of display logic.

**New domain query predicates**

New predicates extend the domain query language, giving you more flexibility and precision. You can now:

* Match strings using:
  * “Starts with”
  * “Ends with”
  * Regular expressions
* Query date and time properties:
  * Within a range
  * Relative to a defined interval

These enhancements support more advanced search, metrics, and display rule use cases.

**Exclude duplicates from domain search and metrics**

A new toggle allows you to control whether duplicate entities are included in domain search results and metrics. This is particularly useful when:

* Multiple models contain the same Entity ID (e.g. through model imports)
* You want a cleaner, de-duplicated view for analysis

This improves accuracy and clarity when working across shared data.

### Usability enhancements

**Model Viewer performance improvements**

Performance improvements have been made across the Model Viewer, particularly for large models. You should notice:

* Faster importing
* Smoother reference relationship editing
* Improved responsiveness when navigating complex models

These changes help reduce friction when working at scale.

**Refreshed model list**

The model list has been redesigned with a cleaner, more modern layout. Updates include:

* All models displayed by default
* Filters for lineage and reference models
* Customisable columns
* Ability to save preferred layouts

This makes it easier to navigate and tailor the interface to your workflow.
