# Import a SOL file

There may be circumstances in which you want to create a copy of a Solidatus Model (perhaps it was created on another Solidatus instance). In this case, you need to export the original Model then import the resulting `SOL` file.

Importing a Model saved as a SOL file (see [Export to a SOL file](/models/explore-and-analyse-models/export-model-content/export-to-sol-file)) is recommended over importing a Model that was exported in any other format. SOL files contain all the information necessary for Solidatus to build the original Model with all original settings, properties, display rules, views, and relationships to Reference Models.

One reason to import a SOL file might be to create a copy of a [composite model](/additional-resources/solidatus-glossary#composite-model) without links to the original Models from which content has been imported. When a composite model is exported as a SOL file, links to imported Models are removed. A Model created by importing this SOL file will be identical to the original composite Model, without any dependencies on imported content - it’s a snapshot of the original Model, and will not be updated by changes to any other Model.

You can import a model from a SOL file directly from the Model Browser (For exporting to a SOL file, see [Export to a SOL file](/models/explore-and-analyse-models/export-model-content/export-to-sol-file)). Note that this will not open the original Model; instead, it will create an exact copy on your instance.

1. In the Model Browser, click the three-dots icon next to the `Create` button in the top right. In the dropdown menu, select ‘Import SOL file’.

<figure><figcaption></figcaption></figure>

2. Select whether you’d like to skip the import of any referenced models found within the SOL file. **Note:** if the SOL file you are importing is a Reference Model, selecting this option will not affect the import. This will only skip Reference Models that were included due to the ‘include referenced models’ flag being true when the SOL file was exported (see [Export to a SOL file](/models/explore-and-analyse-models/export-model-content/export-to-sol-file)).
3. Drag and drop or click and select the SOL file you wish to import. Select the checkbox next to **Skip referenced models** to exclude related reference models contained in the .SOL file from the import.

<figure><figcaption><p>Import multiple models to a file from the model list page - upload dialogue</p></figcaption></figure>

4. On success, an import overview page will show you the imported Lineage/Reference models and their import type (Created, Matched)

<figure><figcaption><p>Import multiple models to a file from the model list page - overview dialogue</p></figcaption></figure>

{% hint style="warning" %}

* If you import a .SOL file of a model that already exists and you are the sole Owner of, the import will entirely overwrite the existing model.
* Similarly, if you are the sole owner of a model and you re-import a .SOL file of that model, you will also entirely overwrite the previously imported Model.
* Importing the .SOL file of a model you co-own, or have Owner permissions to via a Group, does not overwrite the existing model; instead, it creates a new model that you are the sole owner of. If you then re-import the same .SOL file, the above warning applies.
  {% endhint %}

## How to import a single model (model replace)

It is possible to import the contents of the .SOL file directly into a target model that exists and may not have originally been imported. This can be done via the Model Overview of the target model.

This method replaces the entire contents of the target model with the contents of the .SOL file. It can only be used if the .SOL file contains only a single lineage or reference model along with related reference models. In other words, if you've exported multiple models into a .SOL file from the Model Browser, this method cannot be used.

1. From the Model Overview of the model you want to import into, expand the ‘Actions’ tab and select Import. This opens a similar dialogue to that from the models list page.

<figure><figcaption><p>Replace a Model with the contents of a file</p></figcaption></figure>

2. Now follow the same instructions from step 2 above. The file contents are imported directly into the model, overwriting any previously existing model content.

<figure><figcaption><p>Import multiple models to a file from the Model Overview page</p></figcaption></figure>

The overview page shows the ‘Imported Into’ import type next to the target model.
