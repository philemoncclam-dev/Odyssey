# Solidatus 4.4

We are pleased to announce the general availability of Solidatus 4.4.

Solidatus 4.4 is an important release, further boosting our collaboration capabilities with a streamlined workflow for managing collaboration among users, facilitating effective development of models. Solidatus also allows any user with visibility of the model to start a discussion about the model, ask a question, or just make a comment.

The Model Overview now contains an [Activities](/models/share-and-collaborate/activities-and-activity-types/activities) tab, which provides a single location for managing discussions and up-and-coming model changes, such as changes made to an imported model or the parent model for a Fork, or changes submitted via a Task or a Fork.

We have also simplified the process for cloning a model and enabled the creation of a model fork or clone containing only selected content.

As always, we encourage all feedback to be shared with us at [support@solidatus.com](mailto:support%40solidatus.com).

***

### Collaboration

The Solidatus collaboration features support a variety of different scenarios, which are briefly described in the documentation.

* Peer review
* Contribute to someone else’s model
* Discuss a model
* Sharing the editing workload
* Asking someone to help
* Handing over ownership

The new [Activities tab](/models/share-and-collaborate/activities-and-activity-types/activities) on the Model Overview allows a user to see at-a-glance all in-progress updates for a model, and use this to manage workflow.

### Forking a Model

A Fork no longer needs to contain all of a model - you can now create a Fork that only contains a selection of entities.

### Cloning a Model

Creating a copy of an existing model has been simplified, with the introduction of the ability to clone all or part of a model. You can still choose to detach a fork from a model, or export and import a Solidatus model.
