# Running the connector

The connector can either be run in standalone mode or agent mode.

**Agent mode** is used to start the connector as an agent service, which registers itself with Solidatus. You can configure a job interactively, run, and monitor the job from the Solidatus connectors dashboard. **Standalone mode** runs a one-off job.

The connector is run using the same command for either mode:

```bash
java -jar solidatus-webfocus-X.X.XX.jar
```

This will use your `application.yaml` file (see [configuration options](/connectors/connector-specific-documentation/solidatus-webfocus/configuration) for details) that must be located in either:

* The current directory
* The `config/` subdirectory of the current directory
* The immediate child directories of the `config/` subdirectory (see [Spring Boot external config](https://docs.spring.io/spring-boot/reference/features/external-config.html) for more details)

To specify a custom location for `application.yaml`, use:

```bash
java -jar solidatus-webfocus-X.X.XX.jar \
--spring.config.location=[path/to/application.yaml]
```

### Command Line Arguments (**not** recommended)

```bash
java -jar solidatus-webfocus-X.X.XX.jar \
--spring.profiles.active=connector \
--solidatus.agent.name="Solidatus WebFOCUS Connector" \
--solidatus.api.token="123abc45de789f0" \
--solidatus.api.host="https://xyz-group.solidatus.com"
```

> The agent name `solidatus.agent.name` should be unique. Otherwise, the agent registration will fail if another agent exists with the same name.
