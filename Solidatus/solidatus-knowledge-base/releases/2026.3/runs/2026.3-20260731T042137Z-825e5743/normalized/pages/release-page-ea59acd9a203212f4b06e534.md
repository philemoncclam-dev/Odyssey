# Solidatus 5.1

This is a maintenance update with some minor improvements.

### Feature Improvement

**Visibility of Tasks on the Groups overview**

Allows you to see the [Tasks](/models/share-and-collaborate/activities-and-activity-types/tasks) shared with the group.

**Additional filters for My Activities**

Allows you to focus on [Activities](/models/share-and-collaborate/activities-and-activity-types/activities) within Models that have been shared with you or with Groups you’re a member of, and on Activities in Models that you own.
