# Data Map interface

<figure><figcaption></figcaption></figure>

1. Use these tools to change the applied visual context, save a Data Map view, apply a focused trace to a selected entity, or view and apply Display Settings.
2. Navigate the Data Map using the recenter and zoom buttons.
3. Apply a focused trace to show only lineage involving the selected entity.
4. Collapse an expanded visual context grouping.
5. Click OVERVIEW or SOURCES/TARGETS to view information about the selected entity.
6. Collapse and expand entities in the Data Map by clicking the chevron.
7. Click `VIEW MORE` to go to the Entry Page in the domain for the selected entity.

## Data Map views

<figure><figcaption></figcaption></figure>

The expanded Data Map views tile gives you access to all views that have been created in the Data Domain.

<figure><figcaption></figcaption></figure>

1. Search for a Data Map view by name.
2. Click the name of a Data Map view to open it.
3. You can delete a Data Map view from the three-dots menu.

{% hint style="warning" %}
Only Owners of a domain can create and delete Data Map views.
{% endhint %}
