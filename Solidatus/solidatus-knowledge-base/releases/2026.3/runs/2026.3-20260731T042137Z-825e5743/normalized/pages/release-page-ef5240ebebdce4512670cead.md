# Edit and delete an Analytics report

You can edit all aspects of an Analytic Report you have created, including renaming a report, editing metric and tile configurations, and deleting a report. You can also edit and delete reports directly from the Analytics Reports list on the Data Domain homepage, without needing to open the report.

{% hint style="success" %}
Only Owners of a Data Domain can create and edit Analytics Reports. The `Settings` tab and the three-dots menus will not appear to Members of the domain.
{% endhint %}

## Rename an Analytics report

To rename an Analytics report, use the three dots menu in the list of analytic reports.

Optionally, go to the `Settings` page (Don’t forget to click `SAVE` after you’ve edited a name or description).

## Edit metrics

To edit metrics, click the three dots menu on the right hand side of the row containing each metric.

<figure><figcaption></figcaption></figure>

The dialog for editing a metric only has two tabs: Name and Match criteria. You can edit match criteria using either Basic or Advanced mode; just remember to click SAVE at the bottom right of the dialog.

<figure><figcaption></figcaption></figure>

You will see the number of tiles that contain the metric you are editing next to the SAVE button.

## Edit and reposition Tiles

You can change the name and description of Tiles, change the tile type and metrics displayed in them, and resize and reposition them on the page.

To edit a Tile, hover your mouse over it and click the pencil icon. You delete the Tile using the bin.

<figure><figcaption></figcaption></figure>

The dialog for editing a Tile contains tabs for modifying the name and description, included metrics, and chart type.

<figure><figcaption></figcaption></figure>

You can move Tiles around the page by clicking the two-lines at the top-left and dragging. You can resize Tiles by clicking and dragging the arrows along the edges that appear when you hover your mouse over the tile.

<figure><figcaption></figcaption></figure>

## Delete an Analytics report

From the Analytics Reports list on the Data Domain homepage: Click the three-dots menu on the right-hand side of the report row and select Delete. This allows you to delete a report without opening it. From within the report: Navigate to the Settings tab and click Delete in the Advanced section.

Note that only Owners of a Data Domain can delete Analytics Reports; Members of a domain will not see the three-dots menu on the right-hand side of the row of a report.
