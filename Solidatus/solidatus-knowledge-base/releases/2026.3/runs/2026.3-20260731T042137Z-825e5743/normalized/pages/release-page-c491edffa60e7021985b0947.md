# Create an Analytics report

Creating a new Analytics Report is as simple as two clicks.

{% hint style="warning" %}
You will only be able to create Analytics Reports if you are an Owner of a Data Domain.
{% endhint %}

First, go to your list of Analytics Reports by expanding the tile on your Data Domain landing page.

<figure><figcaption><p>Go to the list of all of your Analytics Reports</p></figcaption></figure>

Then click `+ CREATE` at the top-right corner of the expanded list of Analytics Reports.

<figure><figcaption><p>Create a New Analytics Report</p></figcaption></figure>

{% hint style="success" %}
If there are no Analytics Reports in a Data Domain, you can create your first one directly from the Data Domain homepage.
{% endhint %}

When you create a new report, you will be taken to the `Tiles` page, which will be empty until you [create metrics](/data-domains/analytics-reports/create-and-edit-metrics) and use them to [create tiles](/data-domains/analytics-reports/create-and-analyse-charts).

<figure><figcaption><p>The homepage of a new Analytics Report</p></figcaption></figure>

An Analytics Report is made up of three sections:

* **Tiles** - Displays charts and infographics created in the report and enables you to edit them.
* **Metrics** - Lists metrics you have created in this report and enables you to create and edit them.
* **Settings** - Contains sections for editing the name and description of the report or deleting it.
