# Build and edit models

The pages in this section provide information you need if your role includes planning, designing, building, or updating models.

Building a model involves many distinct functions and actions:

* Creating an empty model
* Adding entities manually
* Importing all types of model content from external files (CSV, JSON, XML)
* Connecting entities within a model using Transitions (manually or using the Auto-mapper)
* Adding entity properties
* Connecting entities to terms in reference models via reference relationships
* Understanding and harnessing version control features (forks and revision history)

{% hint style="success" %}
This section does not cover creating, building, and updating models using Connectors or the API. For documentation on those functions, see the [Connectors](https://github.com/solidatus/Solidatus-docs-gitbook/blob/stable/solidatus-core/models/build-and-edit-models/broken-reference/README.md) page and [The Solidatus API](/api-documentation/api-overview) page.
{% endhint %}
