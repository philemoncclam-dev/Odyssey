# Model Viewer Toolbar

The Model Viewer Toolbar provides access to a variety of great features.

<figure><figcaption><p>The Model Viewer Toolbar</p></figcaption></figure>

If your Model Viewer has fewer options than you can see here, that’s because you only have read-only access to the model. You also might be in [Diff Mode](/models/build-and-edit-models/diff-mode), in which case the toolbar options are different and depend on the diff scenario.

## Minimising and maximising the Model Viewer Toolbar

The Toolbar can be minimised to make more screen space available for your model.

<figure><figcaption><p>The Model Viewer Toolbar, minimised</p></figcaption></figure>

To minimise the toolbar, select the chevron at the top of the toolbar.

<figure><figcaption><p>Minimising the Model Viewer Toolbar</p></figcaption></figure>

To maximise the toolbar again, select the chevron at the top of the minimised toolbar.

<figure><figcaption><p>Maximising the Model Viewer Toolbar</p></figcaption></figure>

## Sidebar

The [Sidebar](/the-user-interface/models-ui/model-viewer/model-viewer-sidebar) on the right of the screen provides access to information about selected entities (including their properties, transitions, relationships), including access to reference models and various tools to help you analyse the model. See the Tools panel for some very useful features for controlling how the visualisation changes as you select and/or trace entities.

## Working with model content

Lineage Models represent “flow” (of data, responsibility, control) and are likely to consist of multiple Layers, with possibly hundreds of thousands (or more) child entities, plus a multitude of transitions connecting them. Reference models generally have a hierarchical structure, e.g. a *data dictionary* or regulatory terms, and generally consist of a single layer. The Model Viewer for both Lineage and Reference Models is the same with the exception of the background colour (Reference Models are pale green).

Solidatus provides a variety fo features to help you to understand, navigate, and make use of your models. See [Navigate a Model](/models/explore-and-analyse-models/navigate-a-model) to find out more.

Adding and editing content in a Solidatus model is very simple and intuitive, and you can read more at [Add and Edit Model Entities](/models/build-and-edit-models/add-and-edit-entities).
