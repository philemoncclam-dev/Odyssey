# Solidatus 4.2

After several months of development, we are pleased to announce the general availability of Solidatus 4.2.

Solidatus 4.2 is an important release, focusing on version control and multiple ownership of models, providing a major boost to the ability of Solidatus users to collaborate.

As always, we encourage all feedback to be shared with us at [support@solidatus.com](mailto:support%40solidatus.com).

***

### Version Control and Model Roles

Model roles can be assigned to multiple users and/or groups

e.g. multiple ownership or group ownership

Before version 4.2 model Owners could edit a model without creating a Fork - each model had a single Owner. Other users would create a Fork to edit the model, then raise a Pull request to ask the Owner to merge their changes. This does not reflect the way organisations share responsibilities, so we’ve made it possible for a model Owner to assign *Owner* permissions to other users. Now a model can be edited by two (or more) users simultaneously, and users will be prompted to synchronise changes when their working copy becomes out of date.

“Drafts” system has been revamped

Users can now more easily work with their recovered drafts and can have multiple drafts in progress

***

### Model Overview

The Model Overview has been given a makeover, splitting the content onto separate tabs

* New revisions tab on the Model Overview makes it easier to find and compare revisions
* Revisions can be tagged (e.g. to “bookmark” a point in time)

***

### Documentation

Enhanced content has been created

* New pages describing the Model Browser, Model Viewer, and Model Overview
* New *Collaboration* section with new content
* Some existing content moved from *Advanced* to *Collaboration*

***
