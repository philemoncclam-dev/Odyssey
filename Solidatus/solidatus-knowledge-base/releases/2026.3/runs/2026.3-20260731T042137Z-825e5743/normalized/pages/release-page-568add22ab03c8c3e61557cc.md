# Troubleshooting

## Tableau connector FAQs <a href="#tableau-connector-faq" id="tableau-connector-faq"></a>

### Tableau connector setup <a href="#tableau-connector-setup" id="tableau-connector-setup"></a>

* The Tableau connector is erroring with this message on setup: `self signed certificate in certificate chain`
  * This could be due to a rejection from a proxy or firewall. The Tableau connector is a Node.js-based packaged executable; as such, it requires the user to add to its list of "well-known" certificate authorities. If not, `node-fetch` (the library that sends https requests) will not be able to get its requests forwarded through the proxies. Check the README for the environment variables section for help.
* The Tableau connector is erroring with this message on setup: `connect ETIMEDOUT <ip-address>`
  * This could be due to the connector not being able to access the Solidatus host provided in the settings file. Please ensure that the proxy provided in the `proxy` field is correct (with port).
* The Tableau connector is erroring with this message on setup: `EPROTO <...:error:...> SSL routines:ssl3_get_record:wrong version number:../deps/openssl/openssl/ssl/record/ssl3_record.c:354:`
  * This is a protocol error with either the proxy URL or Solidatus URL. Please ensure that the proxy provided in the `proxy` field or the Solidatus host provided in `solidatusHost` have the correct protocol.

### Tableau instance direct connection

* The Data Origin wizard mode step failed with: `The connector agent found errors in the following fields: request_error: Failed to sign in`
  * This is a generic sign in error from the initial connection test to your Tableau instance. Please verify:
    * that your site content URL and host follow the structure suggested in the tooltips on the Data Origin wizard mode step.
    * that your token name and token secret are correct as per your Tableau PAT (Personal Access Token). This can be found under the "My Account Settings" page. See the example below of a token being created.

### Errors <a href="#errors" id="errors"></a>

During execution, the connector may output various errors and warnings, which require different actions depending on their severity. A list is provided below:If you encounter an error which is not in this list, or cannot be resolved after consulting it, please report to Solidatus along with the troubleshooting steps you have followed.

|                                                                                                        |                                                                                                                                                          |                                                                                                                      |
| ------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| `Model update failed! : ...`                                                                           | A problem was encountered when attempting to save a model to the Solidatus instance. The lineage was generated correctly, but not uploaded to Solidatus. | Action is required. Investigate the error following the details provided in the error message.                       |
| `Unknown connectorMode ... specified`                                                                  | The provided connectorMode is not a valid connectorMode                                                                                                  | Populate this field with either `standalone` or `agent`.                                                             |
| `The provided file could not be parsed or is empty.`                                                   | The provided file could not be parsed or the connector could not generate any valid content from this file.                                              | Please verify if this file is of the `.twb` file format and has been generated by Tableau export utility.            |
| `Connector config validation error: Missing 'solConnection.apiToken' or 'solConnection.host' value(s)` | The Tableau connector requires both a valid Solidatus Host and a valid Solidatus generated API token                                                     | Please provide both a valid Solidatus Host and a valid Solidatus generated API token in the config.                  |
| `Connector config validation error: Missing or incorrect 'connectorMode' value`                        | The Tableau connector should only be able to be run in either standalone or agent mode.                                                                  | Populate this field with either `standalone` or `agent`.                                                             |
| `Please provide either a file path or a direct file upload for the connector to process.`              | The Tableau connector will need to be provided with a file to parse by either a file path or a direct file upload.                                       | Ensure that either a file path or a direct file upload on agent mode is provided for the Tableau connector to parse. |
| `File ... cannot be found.`                                                                            | The file provided at the provided path could not be found.                                                                                               | Please ensure that the file at the provided path exists.                                                             |
| `Could not find resourceId or fileName for uploaded resource.`                                         | The uploaded file resource could not be found.                                                                                                           | Report the error to Solidatus.                                                                                       |
