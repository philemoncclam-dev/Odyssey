## 6.5 - December 2025

This release delivers powerful enhancements to existing functions and introduces a game-changing new capability: [**Data Assets**](/models/understand-solidatus-models/data-assets-101).

With the 6.5 release, we also launched this new Solidatus documentation site – docs.solidatus.com – to improve the self-service support experience on your Solidatus journey.

Read the [6.5 Release Notes](/release-notes/release-notes-main/solidatus-v6-change-summary/solidatus-6.5) to learn about all new features, usability enhancements, bug fixes, and customer-requested fixes in Solidatus 6.5.

## 6.2 - October 2024

The updates in version 6.2 focus on Data Domains and Data Maps, advancing both our industry-leading fine-grained lineage and our business-oriented capabilities.

With new features, customer-driven improvements, and usability enhancements, version 6.2 enhances the flexibility, efficiency, and visual impact of Solidatus, making it easier than ever to explore and manage your data landscape.

Read the full [6.2 Release Notes](/release-notes/release-notes-main/solidatus-v6-change-summary/6.2-release-notes) for information on all new features, usability enhancements, and bug fixes in this release.

## 6.1 - August 2024

We’ve added new features that boost your ability to analyse the contents of a Data Domain:

* A Data Domain Query Language and Query Helper
* Quantitative Analytics Reports for Data Domains
* An updated information structure for domain entries

Additionally, we improved Data Map navigation, enhanced Reference relationship analysis capabilities, and added new filters for refining the results of a Data Domain search.

**Special note** : We changed the path structure for importing entities in tabular format from`/Object/Group/Attribute` to `/Layer/Object/Group/Attribute` to make it consistent with the exportformat. You can now export and reimport without altering entity paths, but the previous path format for importing no longer functions.

Read the full [6.1 Release Notes](/release-notes/release-notes-main/solidatus-v6-change-summary/6.1-release-notes) for information on all new features, usability enhancements, and bug fixes in this release.
