# Data Maps

{% hint style="info" %}
Data Maps require WebGL2. This may require hardware acceleration to be supported by your hardware and enabled in your Operating System and browser. To check if WebGL2 is supported, please visit <https://get.webgl.org/webgl2> from your usual browser.
{% endhint %}

Data Maps are interactive visualizations that show how data flows across the landscape captured in a Data Domain. They combine lineage from multiple models into a single, explorable map that can be organized and summarised by high-level, business-friendly categories.

<figure>A Data Map showing technical lineage in the context of Products<figcaption><p>A Data Map showing technical lineage in the context of Products</p></figcaption></figure>

Data Maps provide two key capabilities:

**Cross-model lineage**: Automatically stitch together lineage from multiple models to show complete, end-to-end data flows across your organization.

**Business context**: Organize technical lineage into meaningful categories like business functions (Finance), products (Credit Cards), or logical domains (Data Warehouse).

{% hint style="success" %}
A Data Map is automatically generated when a Data Domain is created and models are published to it.
{% endhint %}

You can explore Data Maps in three ways:

* **Full domain view**: See all lineage in your Data Domain in one comprehensive map
* **Saved views**: Access specific, saved perspectives from the domain homepage
* **Focused traces**: View lineage for individual data elements from their domain pages

For more information on the integration of Data Maps in Data Domains, see [Understand Data Maps](/data-domains/data-maps/understand-data-maps) and [Understand Data Domains](/data-domains/understand-data-domains).
