# Solidatus 5.6

This is a maintenance update with some usability improvements and bug fixes.

## Usability enhancements

### Import/Export

**Added ability to toggle whether to add derived transitions when doing csv import**

Added an option in advanced section of csv importer to toggle whether the importer should add transitions derived from other entities’ sources and targets provided in CSV. Defaulted to ‘on’.

### Reference Models

**Updated the relationships view for reference models**

Clarified the naming and description for outgoing and incoming relationships, to differentiate between relationships to the selected term and the selected term’s own relationships.

**Added response when deleting all relationships from an entity to a reference model**

Updates the UI immediately when deleting all of an entity’s relationships to a reference model via the Inspector tab in the sidebar.

### Audit and Reporting

**Updated the information captured for model name change as an** `auditevent`

For a model name change in the `UpdateModelSettingsEvent`, it now includes the previous name and excludes extra information not related to a simple name change.

### Updated Security Features

**Updated SSO verification default**

By default now re-verification is required for SSO daily upon login to the Solidatus UI. This configuration is specified in the SSO JSON security file.

**Enable filtering of network and security hosts**

Allow or block network communication based on host or domain name or specify rules to determine which hosts are allowed or denied access. This configuration is specified in the property files as `Solidatus.NetworkAndSecurity.AllowedHosts` and `Solidatus.HostAddress`.

**Updated role of Super Admin to Site Admin**

Updated the system role name of `Admin` to `Site Admin`. This change does not require migration of Super Admins as all previous Super Admins will now be designated as Site Admins.

**Updated permissions for Site Admins**

`ViewLogs, ViewConfig, ViewStatistics, ViewUsers, ManageUsers, ManageLicence, ManageDbOps, Impersonate, AdminHubspot, ManageGroups, ManageAgents, ManageJobs, ViewServiceAccounts, ManageServiceAccounts, ViewSearchState, ManageSearchState, ExecuteElasticsearchQuery, ManageModels, LogIn` and `ApiAccess`.

**Permissions no longer available for Site Admins**

`Create Dashboard, Group, Task, Model, ServiceAccount and Agent, cannot approve the issues, cannot edit or delete Task, Agent, Job and AgentPermission, cannot perform ExecuteJob, ExecuteSearch, ExportModel, ForkModel, GraphExplorer, ManageAgents, RegisterAgent, ShareModel, ViewAgent, ViewDashboard, ViewJob` and `ViewModel`

## Bug fixes

### Import/Export

**Fixed relationships not showing up in export of model**

Ensured that relationships are included in the CSV model export when user selects the `all columns` option.

**Fixed remove children workflow when importing tabular data**

If the `Remove children` option is selected when importing tabular content, all children (not just attributes) are removed from entities that are not included in the import.

### Performance

**Improved speed of search feature of Reference panel**

Fixed the slow speed of search response in the Reference panel by improving the performance of search on the reference term tree list.

**Support Search and Dashboards on multi Solidatus node deployment**

Fixed the ability to perform search or view dashboards on a multi-node environment.

**Improved performance for AutoMapper**

Improved the performance of AutoMapper to prevent crashing the browser for large jobs.

**Improved performance when selecting all children on a large model**

Fixed the count number and selection displayed due to performance issue when selecting all child models of a large composite model.

**Added property is not added to suggested list immediately**

Updated so a new property added is immediately added to the suggestions list once it was successfully added to the first entity.

### Other

**Removed references from previous model for cloned models**

Removed the references and relationships copied from the original model when creating a clone.

**Fixed search workflow once model is selected and filtered**

Fixed bug where searching then selecting a model and applying a filter clears selection of the model.

**Enabled copying of property in read-only mode**

Enabled read-only users to view a complete property value and to copy it to their clipboard.

**Ensure that display rules apply to newly-revealed objects in Lineage Explorer**

Fixed the scenario where display rules were only applied to the originally-selected entities, and not to additional entities revealed using the lineage explorer.

**Fix double tags that appear when display rules are created via relationships panel**

Removed the duplicate tag created when display rules are defined in the relationships panel.

**Enable deleting a user if they own a model and have created a draft**

Fixed the workflow to enable a user to be deleted if they are the sole owner of a model and they have created a draft in that model.
