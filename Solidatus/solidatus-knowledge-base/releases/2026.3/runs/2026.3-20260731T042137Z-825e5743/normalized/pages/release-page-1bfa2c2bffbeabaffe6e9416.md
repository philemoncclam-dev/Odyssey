# Solidatus 6.4

Solidatus 6.4 brings several performance and usability enhancements to make your workflows more efficient and your data easier to find.

Read on to learn about all the usability enhancements, bug fixes, and customer-requested fixes in Solidatus 6.4.

### Usability Enhancements

**Case-insensitive Data Domain search**

Data Domain search is now case-insensitive, so you can find entities without having to match exact capitalization patterns. Simply type what you’re looking for and get the results you need.

**Faster imported model updates**

Composite model workflows are now more efficient thanks to improved performance when merging changes to imported content from original models.

**Download connector logs from run history**

You can now download run logs for any connector job with a simple download button on the job’s run history page.

**vBeta API now available through Swagger**

You can now view and interact with our vBeta REST API through our Swagger API documentation site. Just select the vBeta API from the dropdown at the top right of the Swagger page.

**Return abbreviated model data through the API**

A new API endpoint – `GET /api/vbeta/models/non-extended` – returns a simplified version of model JSON data for more efficient parsing.

**Filter zero-change Pull Requests from Activities list**

You can now remove Pull Requests auto-generated by scheduled connector jobs that contain zero changes from your Activities page, preventing them from cluttering the list.

**New UI indicator for unresponsive connector agents**

A new indicator on the Agents list on the Connectors page now informs you if an agent has become unresponsive and may need to be executed again to reestablish a connection.

**Multi-select property tags display as pills**

When you create a display rule to tag entities with the values of multi-select properties, values are now displayed in a separate pill for each distinct value, rather than as a comma-separated list.

**Model Browser now shows number of revisions for each model**

The list of models in the Model Browser now shows the number of revisions for each model next to the total number of entities.

**JSON exports now include entity relationships**

When you export a model in JSON format through the Model Viewer, the exported data now includes Reference relationships for all exported entities.

**Consistent change count on model diff panel**

In Diff mode, the panel in the Inspector tab displaying changes between model versions now uses a consistent variable to calculate the number of changes, which results in consistent accounting in the panel and “Show changes” list.

**“Sample templates” section on tabular importing dialog**

The dialog for tabular importing clearly labels the section that contains our downloadable sample templates, so you can find and use them more easily.

**New login screen for read-only links**

When accessing a model through a read-only sharing link, a new dialog with an SSO option invites you to log in to Solidatus to view the model.

**Updated query language reference in Model viewer**

The query language reference in the Query Builder has updated descriptions and a more comprehensive list of query language components to help you build the queries you need.

**Sections of the Data Domain browse tree are resizable**

Sections for domains and models in the Data Domain browse tree can be resized independently of one other, making it easier for you to navigate the browse tree.

**Resizable property editor dialog**

The property editor dialog in the Model viewer is now resizable, making it easier for you to view and edit long property values.

**Resizable Save Data Map dialog**

The dialog for saving a Data Map view is now resizable, making it easier for you to add and edit long descriptions.

**Error message when changes made to imported model**

When reviewing an Import Model Update activity in Diff mode and new changes are saved to the imported model, a new error message indicates that you must refresh the page to merge updates.

**Error message for property keys with empty path segments**

Adding “/” to property keys generates a path that results in a nested property folder for each segment in the path. When multiple “/” in a row occur in a property key, instead of creating empty levels of nested property folders, an error icon appears in the Properties and Relationships panel.

**Realigned “Filter based on selection” toggle in Reference Model panel**

The “Filter based on selection” toggle is now left-aligned to prevent to tooltip from blocking other buttons in the panel.

**Auto-mapper indicates when multiple technologies are detected**

The Auto-mapper indicates when multiple source technologies are detected when AUTO is selected for source and target and SOL.UID is selected as the comparison criterion.

**Copyable entity names in the Selection panel**

You can now highlight and copy entity names in the Selection panel of the Inspector tab in the Model Viewer.

**Password masked in JDBC job configuration**

The password you enter in a JDBC connector job configuration for access to a third-party database is now masked, so it is not visible to you or anyone with access to the configuration.

**Cannot delete user with higher admin privileges**

Users who have client admin privileges are no longer able to delete users with site admin privileges.

**Blank agent names are no longer permitted for connectors**

Solidatus no longer allows you to register an agent without providing a name.

### Bug Fixes

**UI issues in BRANCHES section on Model Overview**

We fixed overlapping icons and the visibility of the “Show more” and “Show less” buttons in the BRANCHES section on the Entities or Terms tab in the Model Overview.

**Fixed alignment of Transitions for centered model view in Diff mode**

When you apply a centered layout to the Model Viewer (via your Account settings), Transitions are no longer misaligned in Diff mode.

**Read-only share links require authentication by default**

Solidatus environments require authentication to access a model via a read-only sharing link as a default configuration setting.

**Text on the read-only sharing dialog now accurately reflects the need to authenticate**

Text on the dialog for creating and managing read-only sharing links now indicates that users must log in to Solidatus to access a model via a sharing link.

**Default height set for domain list in browse tree**

If you have access to many Data Domains, the browse tree no longer shows them all by default, making it more usable.

**New Tiles in Analytics Reports no longer replace existing tiles**

We fixed the issue where newly created Tiles on Analytics reports would replace existing Tiles.

**Fixed visibility of query examples in metric creation dialog**

We fixed the issue where the example queries were cut off in the Advanced metric creation dialog.

**Fixed “SAVE” button in Data Domain settings**

The SAVE button in Data Domain settings is no longer disabled when models are removed from a domain.

**Fixed detached Properties and Relationships panel**

We fixed the tendency of the **Properties and Relationships** panel to revert to a detached state after being re-attached.

**Invalid property queries no longer return matches**

Queries in the Model Viewer without single or double quotation marks around property values no longer return matches.

**Special characters and diacritics display correctly in a Data Map**

Special and non-English characters now display correctly in Data Maps.

**Fixed notifications for Approvers of a task**

We fixed notifications for Approvers of tasks. When users are assigned as approvers on tasks, they receive a notification.

**Imported models appear without page refresh**

When you import a SOL file from the Model Browser and click ‘X’ instead of ‘OK’ to close the dialog, the model appears immediately without requiring a page refresh.

**Fixed revision tags disappearing after page refresh**

Previously used revision tags no longer disappear from the quick menu for adding tags to a model revision in the Revisions tab of the Model Overview.

**Tooltip for truncated Entity IDs in Data Map side panel**

Hovering over a truncated entity ID in the Data Map side panel now activates a tooltip that shows the full ID so you don’t have to resize the panel.

**Fixed “Related Entities” tab in Data Domains**

We fixed the issue where using the search function on the “Related Entities” tab in Data Domains caused the list of related entities to disappear.

**Context filter for domain search persists after page refresh**

We fixed the issue where applied Context filters for domain search would clear after multiple page refreshes.

**Tag counts in Model Browser update immediately**

When a tag is added or removed from a model, the tag count listed in the “Most used tags” section updates immediately, without requiring a page refresh.

**Source technologies properly detected when auto-mapping by SOL.UID**

The Auto-mapper accurately detects source technologies when AUTO is selected for source and target and SOL.UID is selected as the comparison criterion.

**Fixed blank screen when exporting a SOL file**

When exporting a model as a SOL file from the Model Browser, the screen stays on the Model Browser and registers the download successfully.

**Disconnecting connector agent does not reset job configuration**

If an agent process is shut down while a job form is being filled in but not yet saved, the state of the form remains the same and is not reset to blank.

**Cut-off tag text in Display Rule dialog shows an ellipsis**

When the text on a tag is too long to fit in the Display Rule popout dialog, an ellipsis is shown to indicate that it has been abbreviated.

**Filters based on isLayer() query work as intended**

When you create a filter from an isLayer() query, the filter works as intended to collapse Layers when set to “Hide” and expand Layers when set to “Show”.

**Metric creation dialog accurately shows number of matching entities**

When match criteria are entered in the process of creating or editing a metric, the count of matching entities accurately updates with the results of the query.

**Fixed background colour for display rules**

We fixed instances where the colour of an applied tag in the Model Viewer did not accurately match the color chosen in the display rule dialog.

**“View changes since revision” opens in read-only mode**

Using “view changes since revision” to compare the current state of a model with a past state no longer shows options in the toolbar to save or cancel a merge.

**Fixed missing “Imported from” details for imported entities**

We fixed scenarios in which the tooltip showing which model an entity was imported from did not retrieved the required data. The tooltip now works to show the source model for imported entities.

**Fixed importing Transitions by path for duplicate entities**

You can now import Transitions in tabular format by path involving entities in the model that have the same name.

**Fixed tabular imports of Transitions between entities with a / in name**

Importing Transtions by path now works when source or target entities that have the path delimiter “/” in their name, as long as the delimiting character is escaped by a “”.

**Deleting an Analytics report redirects to Analytics reports page**

When you delete an Analytics report, you are redirected to the Analytics reports page for the domain, instead of the main Data Domains page.

**Fixed Display Settings when editing a query**

Matching entities are accurately updated and captured when the underlying query for a Data Map tag is edited.

**Fixed incorrect “Connection lost” messages**

The “Connection lost” message no longer appears in situations where internet connection is active.

**In read-only mode, view lengthy property values in a separate dialog**

An eye icon now appears in read-only mode for property values that exceed the size of their field. Click the eye to open a separate dialog, where you can view the full property value.

**Owners of Reference models shown in a Data Domain**

Owners of Reference models published to a domain appear on the Reference models tile on a domain homepage, even when model owners do not have access to the domain.

**Fetch changes no longer removes horizontal scroll bar**

For models with enough Layers to require a horizontal scroll bar, the “Fetch changes” banner that appears when changes have been saved during a viewing session no longer impacts the visibility of the scroll bar.

**Fixed expanded property viewer in Diff mode**

In read-only Diff mode, the “X” and “Done” buttons on the expanded dialog for viewing the full value of a property now work to close the dialog.

**Error messages for invalid values when creating a user**

When adding details for a new user (username, email, password), an error message appears if the values entered are not valid.

**Fixed Data Map views list for shared domain**

The Data Map views list on a domain homepage no longer fails to load for users with whom a domain is shared.

**Fixed aggregation error when generating a large model via a connector**

Instances in which an aggregation error was encountered while creating a large (> 5 million entity) model via a connector have been resolved.

**Advanced settings properly preserved**

Instances where Advanced model settings would not be preserved after navigating away from the settings page have been fixed.

**Fixed relationship filter menu for domain search**

The menu of relationship filters for filtering domain search results now allows you to select multiple terms at a time.

**Property editor does not save changes if dialog is closed**

The expanded property editor in the Model Viewer no longer saves changes you’ve made to a property value if you close the dialog by clicking the “X”. You must click “DONE” to save changes.

**Fixed list of entities matched by a metric in the Tile drill-down**

The list no longer fails to pick up entities counted by the metric due to a missing parameter in the API request.

**Fixed scrolling in the auto-complete menu for adding relationships**

Vertical scrolling is fixed on the quick menu that opens when you add a new relationship in the Properties and Relationships panel.

**Fixed ability to add property values for nested properties**

Adding a value to a nested property in the Properties and Relationships panel by supply its path in the hierarchy of property folders now functions correctly.

**Fixed cases where rejected changes in Activities are merged**

We fixed cases where rejected changes in an Activity could be merged via Visual Merge in Diff mode, despite having been rejected.

**Fixed Metrics tab when creating a tile**

The tab for adding metrics to a tile no longer becomes unresponsive after navigating to the next tab.

**Disable “Traverse parents and children” fixed**

When a highlighted or focused trace is applied to a model, disabling the “Traverse parents and children” function in the Lineage panel of the Tools tab now updates the trace display accurately.

### Customer-Requested Fixes

* **#14835** – New API endpoint for returning abbreviated model data:

`GET {Solidatus_environment_URL}/api/vbeta/models/non-extended`

* **#16243** – Property manager no longer crashes when a revision ID is missing for a property in the model metadata
* **#16335** – Properties of Reference terms no longer appear on related entities when the term’s properties are viewed in the expanded property value dialog
* **#16396** – The Auto-mapper only attempts to generate mappings after “Generate Mappings” is clicked, preventing large models from becoming unresponsive
* **#16238** – The rejection of deleted views in a Pull Request now registers correctly when a merge is completed, along with all other modifications to views
* **#16329** – Fixed LDAP authentication failure when users had no assigned license role. Users are now assigned the default license role
* **#17290** – Special characters, non-English characters, and diacritics in imported JSON now display correctly in the Model Viewer

## How to Upgrade

SaaS environments will automatically upgrade to 6.4 during the week of August 4-8. Please contact [support@solidatus.com](mailto:support%40solidatus.com) if you have any questions or specific requirements.

Solidatus 6.4 is not currently available for on-premises customers but is expected to become available in September 2025. Contact [support@solidatus.com](mailto:support%40solidatus.com) for any questions.
