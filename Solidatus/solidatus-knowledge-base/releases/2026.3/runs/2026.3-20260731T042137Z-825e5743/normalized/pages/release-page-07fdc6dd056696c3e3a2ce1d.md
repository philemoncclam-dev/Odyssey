# Reference Models tab

This tab allows you to add and modify relationships to Reference Models, and to view information on Reference Models, Labels, and Terms that are linked to the open Model. It also contains a panel that suggests new relationships for a selected entity.

## The Reference Model panel

The Reference Model Panel is a control panel for creating, modifying, and viewing Reference Relationships. It lists all currently loaded Reference Models and allows the user to load more in order to link Reference Terms to entities in the open Model.

Note that Reference Models are not automatically fully loaded into the Reference Model panel when you add them to the list. Instead, the contents of a Reference Model are loaded into your Model as and when you expand its Terms and sub-Terms.

To load the full contents of a Reference Model, click the load-contents-icon icon next to its name.

This panel is the primary way to assign relationships within the user interface, but you can also do so in the [Properties and Relationships](/the-user-interface/models-ui/model-viewer/model-viewer-sidebar/the-inspector-tab#the-properties-and-relationships-panel) panel.

Click on Reference Terms in the Reference Model Panel to open a set of further options in a window on the left. Here, you can view a list of the term’s properties and a list of all entities in the open Model that have a relationship to the Term.

Click `Show Usage` to filter the Model to show only entities with a relationship to the Term. Click `Search` to enter a query in the search bar that will match all entities with a relationship to the selected Term.

## The Relationship Suggestions panel

This panel suggests new relationships for a single selected entity in the open Model.

Next to each suggestion, there is a button to add the suggestion individually and to edit the suggested relationship label.
