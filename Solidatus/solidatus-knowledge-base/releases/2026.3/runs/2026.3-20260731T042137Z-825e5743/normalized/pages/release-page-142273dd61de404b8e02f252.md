# API overview

Solidatus has an extensive, publicly available API to facilitate the process of creating automated workflows, integrations, and autonomous agents to ingest data from third-party sources.

The Solidatus public API can be used to create, view, and edit models, as well as retrieve model data, import data, perform administration, manage workflow, and more.

{% hint style="info" %}
Follow the [API quick-start tutorial](/api-documentation/api-overview/api-quick-start-tutorial) for a brief introduction to creating and updating Solidatus models using the API.
{% endhint %}

It’s easy to get started using the API, all you need is a valid authorisation token and an HTTP/REST client.

[This authentication guide](/api-documentation/api-overview/api-authentication) explains how to obtain and use an API token.

{% hint style="success" %}
A comprehensive developer API reference for all endpoints, methods, endpoint paths, and request schemas can be found through the API documentation link in the help menu of your Solidatus instance.

You can execute API commands directly from the Swagger interface once you authenticate with a valid token.
{% endhint %}
