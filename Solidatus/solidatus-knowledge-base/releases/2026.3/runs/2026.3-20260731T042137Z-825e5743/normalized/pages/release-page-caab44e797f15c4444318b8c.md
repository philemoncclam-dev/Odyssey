# View available connectors

## The Solidatus website

The Solidatus website has a list of [available integrations and solutions](https://www.solidatus.com/integrations/).

An **integration** enables Solidatus to connect to a single external technology, so detailed metadata can be extracted, lineage can be captured, and a model can be built to represent the target system. Some integrations also enable you to export from Solidatus to an external technology.

A Solidatus **solution** is a combination of technology and services that enables more complex integrations between Solidatus and external technologies or technology ecosystems. Examples of such systems are those based on Mainframe, Microsoft Purview, and Fabric.

***

## The connectors portal

The Solidatus **connectors portal** (<https://connectors-portal.solidatus.com/>) is a site from which you can download packages for Solidatus connectors you are licenced to use.

You can also view a list of available connectors, versions for each connector, and changelogs for each connector.

To access the connectors portal, you must obtain valid login credentials, which determine the connectors you and your organisation are licensed to download.

When new releases of connectors become available, you can download them from the connectors portal.
