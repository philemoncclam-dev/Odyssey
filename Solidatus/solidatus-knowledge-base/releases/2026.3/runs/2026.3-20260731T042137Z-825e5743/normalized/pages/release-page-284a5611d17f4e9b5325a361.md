# WebFOCUS

The Solidatus connector for WebFOCUS generates a Solidatus model by extracting column-level lineage from WebFOCUS report (`.fex`/`.trc`) and metadata (`.mas`, `.acx`) files. The connector enables modelling and exploration of data flows with the powerful Solidatus tools, as well as integration with lineage from other sources once inside Solidatus.

The WebFOCUS Connector extracts Runtime lineage. This is different from static lineage - lineage is only drawn from what is executed, and may miss areas that were not executed. This relies on the generation of `.trc` files, which are traces generated from a `fex` report, and represent the actual `fex` queries that were run on report generation. Generating `.trc` files is explained [here](/connectors/connector-specific-documentation/solidatus-webfocus/setup#generating-webfocus-trace-files).

## Overview

The connector processes `.trc`, `.acx` and `.mas` files (generating `.trc` files is explained in detail in the [Setup Page](/connectors/connector-specific-documentation/solidatus-webfocus/setup#generating-webfocus-trace-files)). The `.trc` files contain the runtime `fex` file commands that were executed by WebFOCUS. The connector takes these commands and infers column-level lineage from them, with assistance from the master `.mas` and `.acx` files, which specify the logical and physical data sources respectively.

The connector is a file-based connector only. It does not connect to WebFOCUS directly. Instead, it relies on input files provided to it.

Files must be available on the connector-accessible file-system. Upload of files is not supported.
