# Solidatus 6.3

**Solidatus 6.3 – January 2025**

We’re excited to share what’s new in version 6.3!

This minor release includes updates to Auto-mapping functionality that improve automated model building and offer greater customization to suit your needs.

Read on to learn more about the latest additions and how they can benefit you.

## New features

**Automatically stitch together two models**

We’ve introduced a new, streamlined workflow for using the Auto-mapper to build lineage across two separate models. This simplifies the process of creating composite models, saving you time and effort.

**Customise SOL.UID matching in the Auto-mapper**

You can now customize the minimum number of matching parts in SOL.UIDs for any source technology type (e.g., JSON, Database, API, File), giving you more flexibility for adding relevant lineage connections in bulk.

## Usability Enhancements

**Context model structure takes precedence in Data Map**

The order of entities in the structure of an applied context model determines the layout of a Data Map, even when a Focused Trace is applied to highlight the lineage of a physical entity. This makes it easier to interpret physical lineage through the lens of business context.

**“ADD” and “REMOVE” buttons are clearer for adding columns to Grid Reports**

The grey “Add” and “Remove” buttons for organising columns in a custom grid report have been replaced by a larger “+ ADD” and “+ REMOVE” buttons. This makes it easier to notice that you must click “+ ADD” next to a column before clicking “CREATE REPORT”; otherwise, the column is not added.

**New “CANCEL” button in dialog for selecting a context for a Data Map**

The dialog that appears when you open a Data Map and enables you to select a context to organise the map layout now has a “CANCEL” button that redirects you to the domain’s homepage.

**“Not” operator button includes subsequent predicate inside parentheses**

When you use the “Not” button in the Query Helper, the next predicate you select is placed inside the parentheses enclosing the “Not”, so the logical negation is applied to it.

**Error message for tiles with incompatible number of metrics**

If you select a number of metrics that is incompatible with the chart type you’ve chosen (for example, one metric for a percentage chart or two metrics for a single value chart), an error message indicates the conflict and the save button is disabled.

## Security Update

**Enhancing Product Security**

In line with our ongoing commitment to product security and as part of our regular review process the behaviour of anonymous sharing links will be changing from the 6.3 release. From version 6.3 onwards access to sharing links will require authentication from verified user credentials, anonymous unverified access will no longer be possible. This enhancement strengthens the access controls and helps protect sensitive data from unauthorised users. To ensure continued access through sharing links for the intended recipients, verify that they have at least read-only accounts in Solidatus. If Single Sign On is configured for these users, this will have no impact for the recipients.

## Looking Ahead…

**Data Assets for increased end-to-end lineage performance**

While preparing for the 6.3 release, we’ve been laying the groundwork for our upcoming Data Assets functionality.

This new feature will allow you (and our connectors) to specify well known IDs much like our existing SOL.UID property. These will automatically be stitched together within Data Domains to provide a consolidated view of lineage across application and model boundaries.

Data Assets will reduce redundant information, improve model performance, and streamline the creation of end-to-end Data Maps.

## Bug Fixes

**Using logical operator buttons in Query Helper no longer erases existing query**

When you click a logical operator in the Query Helper, the operator is now added to any existing query you have entered in the dialog.

**“View More” button fixed for entities in a Data Map trace**

The “View More” button in the popout for a selected entity in a Data Map has been fixed. This fixed a small number of cases where the button was missing, particularly for entities in a focused trace that were not the targeted entity.

**Removed scrollbar from bottom of collapsed Model Viewer toolbar**

The unnecessary scrollbar at the bottom of the collapsed Model Viewer toolbar has been removed.

**Updated Query Helper description for \~= comparator**

We updated the description of the query example `Name~= “quality”, “data quality”` to describe the function of the comparator as “contains” rather than “begins with”.

**Fixed Layer spacing button in Model Viewer toolbar**

The Layer spacing option accessible through the “Recenter” menu in the toolbar now functions as intended: it changes the width and spacing of Layers.

**Fixed horizontal scrolling in Model description dialog**

The Model description dialog, accessible from the “MODEL” sidebar tab, creates multiple lines to fit long descriptions rather than adding a horizontal scroll bar.

**“EDIT” button no longer visible to users without permissions for a Connector Job**

The job description box on the page for a connector job no longer displays an “EDIT” button to users without Owner or Editor permission on the job.

**Fixed overflowing Reference model names in Properties and Relationships panel**

We fixed the issue where long Reference model names overflow in the Properties and Relationships panel.

**Fixed read-only tag when accessing a model through a read-only sharing link**

When you access a model through a read-only sharing link, the “Read-only” tag now appears next to the model name in the navigation bar.

**Fixed display of EntityId query in the Query Helper dialog for Display Settings**

The Query Helper in the Advanced query configuration dialog for Data Map Display Settings now displays the `EntityId=entity_id` example without cutting it off.

**“Learn More” link for Data Map Display Settings now redirects to correct documentation page**

The “Learn More” link in the dialog for Data Map Display Settings now redirects correctly to the Display Settings platform documentation page.

**Fixed blank screen when disabling a focus trace in a saved Data Map view**

When viewing a Data Map view that captured a focused trace applied to a target entity, disabling the trace now refreshes the entire Data Map, rather than causing the screen to go blank.

**Fixed pagination on Data Domain search**

If you navigate past the first page of search results in a Data Domain, conducting a new search takes you back to page one, rather than displaying the new search results on the page number you navigated to.

**Data Domain search no longer lists zero results while the search is processing**

The Data Domain search results page no longer displays “Found 0 results” while the search is still in progress.
