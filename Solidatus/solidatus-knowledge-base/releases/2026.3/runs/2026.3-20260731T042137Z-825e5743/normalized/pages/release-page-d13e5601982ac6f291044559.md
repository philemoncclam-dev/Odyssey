# Databricks

The Solidatus Databricks Connector enables automated extraction and mapping of metadata, lineage, and job information from Databricks workspaces into Solidatus models. It connects to Databricks using secure API credentials, retrieves catalogs, schemas, tables, and optionally Databricks jobs, and builds a comprehensive lineage model that can be visualized and analyzed in Solidatus.

This connector is designed to help organizations understand, govern, and visualize their Databricks data landscape within Solidatus, supporting regulatory, operational, and analytical use cases.

## **Supported Features Overview**

| **Feature** | **Included** | **Coverage**                                                                                              |
| :---------: | :----------: | --------------------------------------------------------------------------------------------------------- |
|  Structure  |       ✓      | Includes catalogs, schemas, tables, and columns ingested using Databricks Unity Catalog                   |
|   Lineage   |       ✓      | Data lineage extracted from Databricks Unity Catalog to visualise the flow of data between table columns. |
