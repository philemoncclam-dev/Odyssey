# Save a model

After making changes to a model, click the `Save` button on the Model Viewer Toolbar.

Saving gives you an opportunity to enter a “commit message” that describe the changes made and the reason for them. It’s an optional step, but you really should provide a message for at least the most important revisions.

The “commit message” appears in the *Summary* and *Revisions* tabs on the [Model Overview](/the-user-interface/models-ui/model-overview), so it will help you locate a particular version of the model should you need to review it or recover any content.

Saving the model creates a new version (what we call a **revision**) of the model.

<figure><figcaption><p>Saving the model creates a new revision</p></figcaption></figure>

The **Revisions** tab on the [Model Overview](/the-user-interface/models-ui/model-overview) provides access to all the revisions for the model.
