# Questions, comments, discussions, etc.

You can create a simple discussion thread that has no impact on the model content, tagged as a q*uestion*, d*iscussion*, or i*ssue*.

These consist of a series of comments from whomever wishes to join in. Only two discussion thread statuses are possible: o*pen* and c*losed*. If a thread is open, anyone can add a comment; if it is closed,

If you click on the `New discussion` button on the Activities tab, a new thread is created, tagged with d*iscussion*. If you click on the drop-down next to the button, you can create a thread that is tagged as a q*uestion*, d*iscussion*, or i*ssue*. Tags can be changed at any time by any user with at least Viewer access to the model.

## List Discussions, etc.

The **Activities** tab on the [Model Overview](/the-user-interface/models-ui/model-overview) provides access to a list of activities for a model, select the **Basic** type of activity in the filter dropdown if you want to show only discussions.

## Close a Discussion, etc.

A discussion can be closed at any time, using the Activity page - click on the `Close activity` button at the foot of the screen. The discussion can be reopened at any time by any user with access to the model.
