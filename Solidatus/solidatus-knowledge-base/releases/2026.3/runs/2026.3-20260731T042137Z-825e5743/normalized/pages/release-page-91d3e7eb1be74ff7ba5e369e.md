# Purview

The Solidatus Purview Connector is a Java based tool to transfer lineage and asset data between Purview and Solidatus. At present it supports transferring assets and lineage from connector-created Snowflake and Oracle models in Solidatus into Purview.

## Features

* Database objects created in Purview
  * Database host or server
  * Tables
  * Views
  * Table Columns
  * View Columns
  * Stored Procedures
  * View column lineage
  * Stored procedure column lineage
* Database objects matched between Solidatus and Purview
  * Database host or server
  * Tables
  * Views
  * Table Columns
  * View Columns
  * Stored Procedures
* Purview asset classifications added to Solidatus model
* Purview glossary terms added to Solidatus model
* Purview asset properties added to Solidatus model
