# Features

## External tables

On AWS, a Redshift serverless database is able to connect to an S3 instance via Redshift Spectrum. Files representing rows of data and their structure can be represented in Redshift as an external table. See [here](https://docs.aws.amazon.com/redshift/latest/dg/c-getting-started-using-spectrum.html) for more information.
