# Create and analyse charts

Charts and other data infographics are displayed in customisable **Tiles** on your Analytics Report `Tiles` page.

<figure><figcaption><p>Create Tiles to Display your Metrics</p></figcaption></figure>

From the `Tiles` page, you can create new Tiles, edit existing ones, and change their size and position.

You can also [View Data Behind Metric Values](#view-data-behind-metric-values) and open domain entity pages in the domain of entities counted by a metric represented in a tile.

{% hint style="success" %}
When you access an entity page through a chart, it opens in a new tab so you can continue to analyse the chart while diving deeper into the data it contains.
{% endhint %}

### Get started

To start using Tiles, you first have to create metrics so you have values to populate charts and infographics with.

Once you’ve created some metrics, go to the `Tiles` tab of your Analytics Report to create your first Tile.

<figure><figcaption></figcaption></figure>

Click `+ TILE`, which appears on an empty `Tiles` page and at the top-right of an Analytics Report.

The dialog for creating a tile guides you through the four simple steps.

> * [Step 1: Name and describe the chart](#step-1-name-your-tile)
> * [Step 2: Select metrics to display](#step-2-select-metrics-to-display)
> * [Step 3: Select a type of chart](#step-3-select-a-type-of-chart)
> * [Step 4: Preview your tile](#step-4-preview-your-tile)

### Step 1: Name your tile

The name you give your tile communicates the content of the data that it presents. Try to make it as easy as possible for viewers to interpret the chart what data it contains (i.e., Data Quality scores by Owner, or At Risk CDEs).

<figure><figcaption></figcaption></figure>

You can also provide a longer description here - feel free to include notes, preliminary interpretations, or conclusions you want to make available to the audience of the report.

{% hint style="success" %}
Recall that anyone with access to a Data Domain will be able to view your report and the Tiles it contains.
{% endhint %}

### Step 2: Select metrics to display

The first step is to select a set of metrics to display in a Tile. The dialog contains a list of all metrics created in this Analytics Report, and you can click to checkbox to include them in the Tile.

<figure><figcaption><p>Select metrics to display in Tile</p></figcaption></figure>

Recall that metrics return single values that represent a count of entities or properties in your Data Domain. As a result, they will all be represented as single values the charts or infographics that include them. Charts use the names of metrics to identify them in the legend of the chart.

### Step 3: Select a type of chart

<figure><figcaption><p>Choose How to Display Metrics</p></figcaption></figure>

Choosing a type of chart or data infographic depends on your analytic purposes.

Analytics Reports currently offer five options:

* Single Value
* Percentage
* Pie Chart
* Horizontal Bar Chart
* Vertical Bar Chart

Each chart type fits certain analytic purposes better than others. Pie charts are optimal for visualising the relative contributions of values to a whole, while bar charts are optimal for comparing value sizes.

You can use Single Value and Percentage charts to keep track of targets and monitor key metrics.

{% hint style="success" %}
Single Value tiles can only be selected if you’ve chosen one metric to display in the previous step.

Percentage charts can only be used if you chose two metrics, and the percentage represents the ratio of the metric you clicked first to the metric you clicked second.
{% endhint %}

Click the bubble at the top-right corner of a chart type to choose it, and then click `NEXT` to continue.

### Step 4: Preview your tile

<figure><figcaption><p>Choose How to Display Metrics</p></figcaption></figure>

Preview your tile on this page, and when you’re ready, click `CREATE` to display it on your Analytics Report. Remember, you can always edit your Tile later or click `BACK` to make changes to previous steps.

{% hint style="success" %}
Recall that everyone with access to your Data Domain will be able to view the Tiles on an Analytics Report.
{% endhint %}

### Examine data behind metric values

Tiles are interactive, meaning that you can click a bar or pie slice representing a metric in a Tile to open more detail on the data behind a metric value.

<figure><figcaption><p>Click bar or pie slice to drill down into metric value</p></figcaption></figure>

The metric drill-down shows a list of entities counted to reach the value returned by the metric.

The entities in the list are clickable and will take you to the item’s page in the Data Domain, where you can further analyse properties, relationships, and lineage.

You can also export the drill-down data to CSV by clicking the **Download** button in the drill-down panel. This gives data stewards quick access to the underlying records behind any metric for reporting or further analysis outside of Solidatus.
