# Solidatus 6.0

Solidatus 6.0 includes exciting new features and capabilities that make the wealth of information in your models more accessible across your organisation. It also includes new usability enhancements and bug fixes.

These notes list changes since version 5.6.8. Please see the final section for customer requested fixes.

## New Features

**Connected Catalog**

*A new user-friendly, self-service metadata and lineage library for the whole business*

The Solidatus Connected Catalog is here. Built on top of industry-leading lineage, Connected Catalog is the “shop window” to your organisation’s data ecosystem. Connected Catalog enables you to bridge the languages of business and IT, so everyone can discover, understand, and trust data in a way that makes sense to them.

*Search and browse curated Data Domains within the Catalog*

Using Connected Catalog is as familiar as searching and browsing the internet. You can make your data assets easy to discover and understand by organising metadata into domains relevant to specific business areas, such as products, reports, or regions.

**Data Maps**

*Stitch lineage from multiple models together, all on one screen*

The Connected Catalog integrates a new Data Maps lineage visualisation tool that allows you to stitch lineage together through several individual Lineage models, making it easier for you to build a view of full, end-to-end lineage for your data.

*Visualise technical metadata and lineage within meaningful business contexts*

Our enhanced lineage visualisation tool allows you to visually organise and summarise your technical lineage according to recognisable business structures and semantics. This allows everyone to visualise, explore, and analyse their data landscape through the lens of business operations and relevant high-level categories.

## Usability Enhancements

**Swagger API page has been restored** – The Swagger API documentation at \<instanceURL>/api-docs has been restored after being taken down for temporary maintenance at version 5.6.8.

**Updated information when removing a user from a group** – The dialog that appears when removing a user from a group contains updated information about what happens to models published by the user.

**The model scope selection dialog in Search no longer overlaps the search bar** – When setting a model scope using Global Search, the list of models no longer overlaps the search bar and browser footer.

**Added debug logs for troubleshooting connector errors** – We’ve enhanced our ability to identify causes of errors in connector Jobs.

**Improved connector jobstream** – An improved connector workflow ensures submitted jobs aren’t missed by registered agents when there is a delay to starting the job subscriber.

**Updated dialog info for bulk creating users** – Information on required fields and formatting has been updated on the Admin page dialog for creating users in bulk.

**Renamed context menu options for expanding sub-entities** – To improve clarity, the context menu options to expand and collapse “all children” of an entity in the Model Viewer have been renamed to “all descendants”.

## Bug Fixes

**Fixed Filter and Show Trace interaction to preserve visibility of Transitions** – Behaviour when activating both Filters and Show Trace has been reverted from the 5.6.8 release to fix disappearing Transitions.

**Fixed legacy property display rules** – Legacy property value display rules from early versions of Solidatus can now be activated as Name Replacement display rules.

**Fixed search in Reference Model Panel for imported Reference terms** – When searching for terms in the Reference Model Panel, terms that have been imported into a loaded Reference model appear in the search results.

**Queries involving Layers are now recognised in the Lineage Explorer** – The Lineage Explorer query tab now responds correctly to valid queries involving Layers.

**Entities automatically expand to show terms matched by a search** – Fixed behaviour of search results in Model Viewer so collapsed entities containing matches automatically expand to show matches.

**Fixed slow automapper for large models** – We fixed the tendency of the automapper dialog to load slowly when a model contains a large number of entities containing several levels of nested entities.

**Fixed performance of tabular imports of Reference relationships** – The slow speed of tabular importing when importing relationships to large Reference models (>100K terms) has been fixed.

**Fixed responsiveness of Model Viewer search bar for large models** – We fixed the tendency of the search bar in the Model Viewer to respond slowly to typed characters for models with >500k entities.

**Fixed irregular Reference Model Panel responsiveness** – Scenarios in which Reference Model Panel could become frozen when searching for relationship suggestions have been fixed.

**Fixed Reference Model panel “expand all” behaviour** – The “expand all” button for a Term in the Reference Model Panel now expands to show sub-terms after one click, rather than two.

**Fixed Reference Model Panel search error** – Reference Model Panel search no longer stalls when user does not have access permission to a Reference model in the list.

**Fixed Reference Model Panel speed and responsiveness** – The limited scenarios in which the Reference Model Panel would become slow or unresponsive have been fixed.

**Fixed sidebar errors caused by deselecting “Filter based on selection” in Reference Model Panel** – Complex cases in which deselecting “Filter based on Selection” resulted in sidebar malfunction have been fixed.

**Selected models are not affected when Model Browser list if filtered by a tag** – Selected models remain selected when filtering the list by model tags, but only appear in the list if they match the chosen tags.

**Fixed performance of tabular imports of Reference relationships** – The slow speed of tabular importing when importing relationships to large Reference models (>100K terms) has been fixed.

**Grid Reports no longer treat brackets as escape characters in paths** – When exporting paths of entities with brackets in their name, a Grid Report export no longer treats the bracket as an escape character.

**Fixed Admin page behaviour when assigning license to a user with higher privilege** – Added error message when a non-site admin attempts to change the license of a site admin.

**Fixed error message when sharing model with a group that already has permission to view the model** – Error messages accurately capture and distinguish between permissions and other sorts of issues.

**Fixed Query Builder validation of invalid queries** – The Query Builder shows red highlighting and a warning icon around the Expression field when an invalid query has been entered.

**Model Overview no longer links to inaccessible Reference models** – The Model Overview no longer shows a clickable link to Terms in Reference Models that users do not have permission to access.

**Fixed unresponsive “Show Changes” button in Diff mode** – Scenarios in which the “Show changes” button was unresponsive in the Inspector tab in Diff mode have been fixed.

**Disabled ability to reorder queries within a module** – In the Queries Manager, the ability to reorder the queries in a particular module has been removed due to inconsistent behaviour. Queries can still be reordered in the list containing “All queries”.

**Fixed Date filter on Admin Events page** – The Admin events page now allows you to select “from” and “to” dates to filter the events listed. The earliest “from” date has been set to 01 Jan 2016.

**License count refreshes automatically when licenses are assigned** – The license count on the Admin page automatically updates when the assignment of licenses is changed.

### User Interface Fixes

**Updated dialog info for bulk creating users** – Information on required fields and formatting has been updated on the Admin page dialog for creating users in bulk.

**Fixed Reference term popout resizing** – After resizing the Reference term popout, the popout no longer appears detached from the Reference Model Panel.

**Fixed flickering scroll bar on Reference Model Panel popout** – When a Reference term is selected on the Reference Model Panel, the scroll bar on the popout showing term information no longer flickers.

**Fixed the outline of Labels in the Reference term popout** – The outline of relationship Labels listed in the popout that appears when selecting a term in the Reference Model Panel has been fixed.

**Fixed the scroll bar on the detached Properties and Relationships Panel** – When the Properties and Relationships Panel is detached from the sidebar, a scroll bar now allows you to view the full contents.

**Search suggestions box appears closer to the Model Viewer search bar** – The list of search suggestions now appears directly above the search bar in the Model Viewer.

**Fixed incorrect application of outline display rules** – Extra highlighting of Layers and Objects that can occur when both filters and outline display rules are applied no longer appears.

**Users page registers edited user settings without refreshing page** – The Users section of the Admin page now stores edited user details after having navigated to another section.

**Tooltip in Permissions section no longer lingers** – The “Show inherited roles” tooltip in the Permissions section of the Model Overview no longer lingers when navigating away from the checkbox.

**Fixed location of tooltips in Lineage Explorer** – Tooltips in the Lineage Explorer dialog are now located closer to the element they describe.

**Fixed green highlighting when hovering over Reference Term** – Green highlighting that appears in on Layers when hovering over Terms in the Reference Model Panel disappears when no longer hovering.

**Fixed lingering Property value tooltip in Inspector tab** – The tooltip indicating “Property value cannot be empty” no longer lingers on the screen when adding and editing properties.
