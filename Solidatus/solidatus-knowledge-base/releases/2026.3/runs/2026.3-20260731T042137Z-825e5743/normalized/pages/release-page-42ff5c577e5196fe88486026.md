# Navigate a model

Solidatus models can grow to many thousands of entities and transitions. You need a way to navigate complex model content so you can explore and analyse it.

This page covers collapsing and expanding, selecting, and searching for entities, as well as filtering a model to highlight the end-to-end lineage of an entity.

## Collapse and expand entities

When the number of entities increases, it is often useful to collapse Objects, Groups, and Layers to focus attention on a high-level view of the model.

Objects are often collapsed by default to show a high-level view. To expand or collapse objects individually, click on the black triangle next to the object name. You can also select the object(s) and hit the spacebar.

<figure><figcaption><p>Collapse objects and layers to create a high-level view</p></figcaption></figure>

{% hint style="success" %}
Double-clicking on a blank part of the screen in the Model Viewer will collapse all objects and disable a focused trace.
{% endhint %}

To expand or collapse Layers individually, click on the inverse arrows to the left of the Layer name. You can also select Layer(s) and hit the spacebar to collapse them.

<figure><figcaption><p>Collapsing a Layer is useful for hiding the internals of the Layer.</p></figcaption></figure>

Where an entity in a collapsed Layer has Transitions to both sources **and** targets in Layers that have not been collapsed, those Transitions will not be lost. Instead, transitions will be displayed that bypass the collapsed layer.

There are also options with in the toolbar and in the **Tools** panel in the sidebar to collapse and expand all objects.

## Zoom in and out

<figure><figcaption></figcaption></figure>

Zooming in and out gives you either a high-level or fine-grained understanding of what a Model represents. In Solidatus, there are a few easy ways to get the perspective on a Model you need:

* Use the Zoom slider at the bottom of the toolbar.
* Open Zoom options using the arrow next to the `Recenter` button in the toolbar (pictured to the right). You can also modify Object widths and Layer spacing from here.
* Open the `Tools` tab in the sidebar and use the buttons in the Zoom panel.

## Select entities

Selecting a single entity in a Solidatus model is as easy as clicking your mouse or tapping your phone screen.

There are times when you need to work on multiple entities together, perhaps to add a property to multiple entities, or to delete or copy those entities. To do this, you’ll need to extend your selection using standard operating system keyboard and mouse actions or the [context menu](/models/build-and-edit-models/add-and-edit-entities#context-menus).

{% hint style="success" %}
In the Model Viewer, selected entities are highlighted with a blue background or line.
{% endhint %}

## Select the children or descendants of an entity

Entities in a model are organised hierarchically: Layers **contain** Objects, which **contain** Attributes, etc.

If you click an entity with the **right** menu button you will open the [context menu](/models/build-and-edit-models/add-and-edit-entities#context-menus). The *Select* section allows you to select two categories of Entities related to the current Entity:

> 1. Entities contained in the selected entity
>    * Entities one level below a selected entity are its **children** (e.g., the Attributes owned by a Group)
>    * Entities that are more than one level below – children of children – are **descendants**.
> 2. Transitions

<figure><figcaption><p>The selection options in the context menu</p></figcaption></figure>

{% hint style="warning" %}

* *Select all descendants* will only select **visible** descendants. If some descendants are hidden by a Filter or are collapsed inside other descendants, they will not be selected using this context menu option.

To select *all* descendants, make sure you expand all descendants first and remove any active filters that may be hiding entities in the hierarchy.

* Selecting entities using the context menu will always **replace** any currently selected entities. If you need to extend the selection after using the context menu, use the [Tools Tab](/the-user-interface/models-ui/model-viewer/model-viewer-sidebar/the-tools-tab) in the *Sidebar*.
  {% endhint %}

## Select Transitions

You can select Transitions in the Model Viewer simply by clicking on them, just like any other entity.

You can also hold down `Ctrl` (Windows) or `Command` (macOS) and click multiple Transitions to select them all.

However, it can sometimes be difficult to isolate a Transition when there are many in the model.

Here is an alternative way to select a Transition:

* Select the source or target entity
* Go the Inspector tab and find the Transitions panel
* Hover over the Transition that links to the desired entity
* You will see a set of buttons appear on the right-hand side
* Click the pointer icon to select the Transition.

<figure><figcaption></figcaption></figure>

{% hint style="success" %}
After you click the pointer icon, the information in the Inspector tab will change to show the characteristics of the selected Transition.
{% endhint %}

## Select everything in a Layer

To select all the Objects, Groups and Attributes in a Layer, right-click the Layer and choose the `Select all descendants` option in the context menu.

## Extend your selection into the trace

Open the [Tools Tab](/the-user-interface/models-ui/model-viewer/model-viewer-sidebar/the-tools-tab) in the *Sidebar* then:

1. enable *Add to selection* by clicking on the slider
2. click on the *Incoming* and *Outgoing* buttons to include all transitions in the selection
3. if you also want to include the source and target entities in the transitions, click on the *Source* and *Target* buttons
4. if you want to include all entities in the trace (as defined in the *Lineage* section of the panel, just click on the *Trace* button in the *Select* options.

## Search a model

The search bar can be activated by hitting `ctrl+f` or the `.` key.

In its most simple form, typing a search term in the search bar will highlight all layers, object and attributes where the name contains the typed search term.

There are more advanced searches which can be performed using queries. For example: `isAttribute() and Owner = 'Danny'`

When a search is active, the button (three dots) besides the search bar allows you to:

* Create a filter for the search results
* Select matched entities (useful for bulk-editing properties)
* Create a display rule for the search results
* Use the query builder to create simple property queries

<figure><figcaption><p>The search bar finds all entities by name or using a query</p></figcaption></figure>

For more information on searching and querying, see [Search and Query in a Model](/models/explore-and-analyse-models/search-and-query-in-a-model).
