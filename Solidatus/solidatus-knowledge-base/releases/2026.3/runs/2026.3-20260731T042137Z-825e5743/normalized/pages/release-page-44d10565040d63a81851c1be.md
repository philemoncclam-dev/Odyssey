# Configuration

## Configuration

Configuration options can either be passed in through command line directly to the connector JAR or through a configuration YAML file. If using a configuration file the parameter `--spring.config.location={YAML_FILE}` must be provided with a valid path to the configuration file.

This would make the execution script look like:

```bash
java -jar solidatus-jdbc-connectors.jar \
--spring.config.location={YAML_FILE}
```

where the rest of the configuration information is included in the YAML file.
