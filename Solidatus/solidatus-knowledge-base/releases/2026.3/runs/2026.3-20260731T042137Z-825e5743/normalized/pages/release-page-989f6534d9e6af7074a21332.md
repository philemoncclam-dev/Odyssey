# Search and browse interface

The Data Domains interface enables you to search or query for an entry from the homepage of a Data Domain. The Domain Spine keeps the main domain areas available as you move through the domain.

## Search from a Domain Homepage

<figure><figcaption></figcaption></figure>

1. Choose whether to search for Lineage entities only, Reference terms only, or both.
2. Enter search terms or a query in the search bar and press `ENTER` on your keyboard to retrieve matches.
3. Open the Query Helper with examples that you can use to build valid queries.
4. Open the domain Data Map.

## Search results

<figure><figcaption></figcaption></figure>

1. Click the name of an entity to go to its page in the Data Domain.
2. View the path of the entity in its original model.
3. Use Context and Relationship filters to narrow results according to relationships to Reference terms. Relationship filters are terms in Reference models published to the domain; Context filters are terms in context models published to the domain.
4. View initials of owners of the original model that contains the entity.

## The Domain Spine

<figure><figcaption></figcaption></figure>

1. Use the Domain Spine to move between Home, AI Assistant, Reference Hub, Lineage Models, saved Data Maps, and other domain areas.
2. Open the area you need without leaving the current domain context.
3. Use search results, model pages, and entry pages to move from high-level navigation into specific content.

{% hint style="success" %}
Use the Domain Spine for domain-level navigation.

Use search results and model pages when you want to jump directly to a specific entry.
{% endhint %}
