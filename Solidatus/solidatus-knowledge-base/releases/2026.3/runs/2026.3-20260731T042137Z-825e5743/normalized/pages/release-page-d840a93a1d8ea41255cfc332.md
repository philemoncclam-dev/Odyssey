# Solidatus 4.3

This is a maintenance update with some minor improvements.

### Feature Improvement

**Improve entity selection interface when importing entities from large models into other models**

Finding entities to import used to involve expanding the model structure looking for entities with the right names - now you can use the search bar to expand the model strutcure to show entities with matching names, filtering as you type.

### Other Improvements

* Prevent large saves from failing in the browser in some environments
* Various bug fixes and stability improvements
* Various smaller usability improvements
