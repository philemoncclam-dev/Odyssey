# Models interface

<figure><figcaption></figcaption></figure>

There are three areas of the Solidatus platform for working with models: the Model Browser, the Model Viewer, and the Model Overview. Use the links in the table to explore the functionality in each model-related area.

<table data-header-hidden><thead><tr><th width="192.32843017578125"></th><th></th></tr></thead><tbody><tr><td><a href="/pages/AAYHmWfCa2yVwuybhJo3">Model Browser</a></td><td>This is where you can find and open all models you can access or create a new model. You can also perform several useful actions including exporting and importing.</td></tr><tr><td><a href="/pages/bwf66p0eYCiZRRQX1vJ1">Model Viewer</a></td><td>This is the canvas for building, exploring, and analysing models.</td></tr><tr><td><a href="/pages/3L8FHSUBYE4OR2NEojD2">Model Overview</a></td><td>This is where you can view model information and work with version control features involving revision history and pull requests for forks. You can also access activities, settings, and permissions.</td></tr></tbody></table>

While the Model Viewer is the main canvas for building and exploring a model, lineage and model content can be explored in other areas that have unique analytical and visual capabilities.

<table data-header-hidden><thead><tr><th width="197.48709106445312"></th><th></th></tr></thead><tbody><tr><td><strong>Area</strong></td><td><strong>Description</strong></td></tr><tr><td><a href="/pages/3L8FHSUBYE4OR2NEojD2">Model Overview</a></td><td>This provides useful information about a model, including a directory of model entities, version history, settings, and links to the other areas.</td></tr><tr><td><a href="/pages/oODQ0GZnNWqNazX6EWpX">Lineage Explorer</a></td><td>This feature allows the user to extract a subset of entities out of a complex model, so you can analyse lineage in isolation from the clutter of other parts of a model.</td></tr><tr><td><a href="/pages/f7FfXW3IbkMeGZGPu76A">Graph Explorer</a></td><td>The Graph Explorer gives you a visualisation of a model as an animated graph. It displays entities as <strong>nodes</strong> and transitions, parent-child links, and reference relationships as <strong>edges</strong>.</td></tr></tbody></table>
