# Configure Job Using Wizard in Solidatus

When the PowerBI connector agent is active, you can configure a job interactively on Solidatus. The job wizard will guide\
you step-by-step to complete a job configuration.

To configure a job using wizard, go to `Edit` -> `Edit using wizard` on top right of job configuration page.

#### Step 1

Specify API token, either model name or ID to be created/updated. Click `NEXT` to proceed.

#### Step 2

Provide a PBIT file either by file path or file upload. Click `NEXT` to proceed.

#### Step 3

Optional step to specify the path for model export in JSON. Click `SAVE CHANGES` to save the job configuration.
