# Overview

The Solidatus Connector for Tableau allows for the importation of data lineage from a Tableau (.twb) file into a Solidatus instance. The connector enables modelling and exploration of data flows with the powerful Solidatus tools, as well as integration with lineage from other sources once inside Solidatus.Within this documentation there will also be reference to direct connectivity to a Tableau instance. This refers to the option to connect directly to a Tableau instance to leverage its API to query and export Tableau workbooks for the connector to ingest.

### **Supported Features Overview** <a href="#supported-features-overview" id="supported-features-overview"></a>

| **Feature**        | **Included** | **Example**                                                                                                          |
| ------------------ | ------------ | -------------------------------------------------------------------------------------------------------------------- |
| Metadata Structure | ✓            | Datasource connection metadata, Tableau logical view structure, Worksheet high-level contents and Tableau components |
| Lineage            | ✓            | Column-level relationships, Workbook-level relationships                                                             |
