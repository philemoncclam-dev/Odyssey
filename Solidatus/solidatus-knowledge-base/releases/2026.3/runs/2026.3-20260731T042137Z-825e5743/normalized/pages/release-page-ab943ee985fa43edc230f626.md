# Activities interface

The **My Activities** page is the core interface for managing, viewing, and completing activities.

It is accessed by clicking **ACTIVITIES** on the [top navigation bar](/the-user-interface/the-navigation-bar).

<figure><figcaption><p>Access all of your Activities through the Navigation Bar</p></figcaption></figure>

## The ‘My Activities’ list

The Activities interface contains a list of all activities you are involved in. The list includes activities you

* created,
* were assigned to (tasks),
* updated (for example by contributing to a revision in the pending change),
* have been invited to approve,
* or left a comment in.

<figure><figcaption><p>The list of my activities</p></figcaption></figure>

The list looks the same as the Activities tab list in the [Model Overview](/the-user-interface/models-ui/model-overview), except there are pre-defined categories to organize your activities in the banner at the top. You can click a category to view only the activities that belong to that category.

{% hint style="success" %}
You cannot edit tags in the **My Activities** page. To edit the tags for an Activity, just click the Activity to open the detail page and edit the tags there.
{% endhint %}

See [Filtering and sorting the list of Activities](/the-user-interface/models-ui/model-overview#filtering-and-sorting-the-list-of-activities) to find out how to filter and sort the list of Activities.
