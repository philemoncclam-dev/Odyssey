# API Quick-start tutorial

This tutorial introduces you to the Solidatus API and takes you through steps to ingest content into a model via the API.

{% hint style="warning" %}
This tutorial requires the curl command line utility.
{% endhint %}

There are four actions covered in this tutorial:

1\) [Request an API token](#request-an-api-token)

2\) [Create an empty model](#create-a-model)

3\) [Add content to the model](#update-the-model)

4\) [Next steps](file:///Users/peterwoodford/Documents/GitHub/solidatus-docs/build/html/api/tutorials/quick-start.html#next-steps)

## Request an API token

All calls to the Solidatus API endpoint need to be authenticated using an API token.

> 1. Go to the API tokens page. This can be accessed by clicking on your initials in the top right of the [the navigation bar](/the-user-interface/the-navigation-bar), selecting *Account*, and scrolling down to the *API tokens* section.
> 2. Enter a name for your new token
> 3. Select the “Create model” and “View model” scopes
> 4. Click “Create token”
> 5. The token will then be displayed for you to copy and use in subsequent commands in the Authorisation header, as shown

{% hint style="danger" %}
Make sure you copy the token right away because you will NOT be able to see it again later. If you lose the token, you will need to create a new one.
{% endhint %}

[Read more about API authentication.](/api-documentation/api-overview/api-authentication)

## Create an empty model

* In the curl command below:
  * Replace the `PASTE_THE_API_TOKEN_HERE` with your API token from above.
  * Replace `https://solidatus-host` with your Solidatus URL.
* Execute the command to create an empty model called “My model”.

**Request**

```
curl --header "Content-Type: application/json" \
  --header "Authorization: Bearer PASTE_THE_API_TOKEN_HERE" \
  --request POST \
  --data '{"name": "My model"}' \
  https://solidatus-host/api/v1/models
```

**Response**

```
{
  "id": "5f06f5a716bd8b0001dc2a03",
  "name": "My model",
  "description": "",
  "type": "LineageModel",
  "referenceModelType": null,
  "owner": {
    "id": "54d0b14018d86418ccfdc157",
    "name": "Joe Bloggs"
  }
}
```

You will use the returned model `id` (e.g. `5f06f5a716bd8b0001dc2a03`) in the following command to update the model.

## Add content to the model

There are many model update commands available to edit an existing model (for a full list of available commands, see [model update commands](/api-documentation/api-actions/api-use-the-api)).

This example uses the *ReplaceModel* command to insert entities using the [Solidatus JSON format](/api-documentation/api-actions/solidatus-json-format).

* First, copy and paste the below JSON to a file called `body.json` and save it.

```
{
  "cmds": [
    {
      "cmd": "ReplaceModel",
      "model": {
        "entities": {
          "1": {
            "name": "My layer1",
            "properties": {},
            "children": ["2"]
          },
          "2": {
            "name": "My object1",
            "properties": {},
            "children": ["3"]
          },
          "3": {
            "name": "My source attribute",
            "properties": {}
          },
          "4": {
            "name": "My layer2",
            "properties": {},
            "children": ["5"]
          },
          "5": {
            "name": "My object2",
            "properties": {},
            "children": ["6"]
          },
          "6": {
            "name": "My target attribute",
            "properties": {}
          }
        },
        "transitions": {
          "3:6": {
            "source": "3",
            "target": "6",
            "properties": {}
          }
        },
        "roots": [
          "1",
          "4"
        ]
      }
    ,
      "comparator": {
        "path": true
      }
    }
  ],
  "commit": true,
  "commitMessage": "Merge in new model data"
}
```

* From the directory containing the body.json file, execute the command to update the model.

**Request**

```
curl -X POST \
  --header "Content-Type: application/json" \
  --header "Authorization: Bearer PASTE_YOUR_API_TOKEN_HERE" \
  --data @body.json \
  https://solidatus-url/api/v1/models/PASTE_MODEL_ID_HERE/update
```

**Response**

```
  {
    "changeset": [],
    "ids": {
        "4": "e6499251-438a-4e01-970d-3fa32b8fb020",
        "3": "0e20ec3c-9e73-44c4-98eb-418d87764261",
        "2": "bbe17ed4-d6f0-4c3a-8724-c58b74ca85d0",
        "3:6": "2fb57996-cb0f-4966-9144-75c8c966f94d",
        "6": "39408d89-60df-4e35-ad1b-6dbb06b70232",
        "5": "dd7474f5-1a17-42eb-b45b-7e79fdf6bff6",
        "1": "ccf0b81b-5b6c-4ee0-8b81-076471de157c"
    },
    "errors": [],
    "revisionId": "67fd1027e37484e1ad33b385",
    "draftId": null,
    "draftRevisionId": null
  }
```

* Go to the model list in the [Model Browser](/the-user-interface/models-ui/model-browser), open it, and you will see the resulting entities.
