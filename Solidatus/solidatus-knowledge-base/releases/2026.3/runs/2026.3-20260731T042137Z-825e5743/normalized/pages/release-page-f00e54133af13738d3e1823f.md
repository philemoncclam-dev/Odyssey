# Model tags

Tags are free-form labels that you can apply to models, revisions, or activities to categorise them in whatever way is useful to you.

The tags on models are displayed (and can be edited if you have the privilege) in the [Model Browser](/the-user-interface/models-ui/model-browser) and [Model Overview](/the-user-interface/models-ui/model-overview), and can be used to filter models in the Model Browser.

{% hint style="success" %}
Only model Owners can create and edits tags. If you are not an Owner, the **+ADD TAGS** or **+Edit tags** buttons will not appear in the Model Browser and Model Overview.
{% endhint %}

Tags are created when they are first used, and can be reused once they have been created. The tags used on models can be shared (public) or personal - personal tags (highlighted by a padlock symbol) are only visible to the user that created them. The tags used on model revisions are limited to the model, as are the tags used on activities.

Existing shared (public) tags are only visible to you if they have been used on models that you have access to.

## Add and edit model tags

Wherever you edit tags, the dialogue is the same. When you click <mark style="color:red;">`+EDIT TAGS`</mark> you are presented with a list of available tags. To find an existing tag in the list, type a string in the *search bar* to filter the list - if the required tag does not exist you can create it.

### From the Model Browser

Hover your mouse over the row of a model and select the open side peek panel button.

## Model revision tags

You can add tags to specific revisions of a model in the Revision tab in the Model Overview. If you’re an Owner of the model, you’ll see `+Edit tags` next to the commit message on the revision.

<figure><figcaption></figcaption></figure>

Click **+Edit tags** to add an existing tag or to create a new one. Only revision tags created for this particular model are listed, and revision tags do not carry over to other models.

## Activity tags

You can add tags to existing Activities for a model in the Activities tab in the Model Overview. If you’re an Owner or Author on the model, you’ll see **+Edit tags** next to the activity description.

<figure><figcaption></figcaption></figure>

Click **+Edit tags** to add an existing tag or to create a new one. Only activity tags created for this particular model are listed as existing tags, and activity tags for a model do not carry over to other models.

## Naming your tags

Tags cannot be renamed or deleted, so please don’t rush into defining them, especially shared (public) tags, which will be visible to other users. Avoid creating tags that are cryptic or ambiguous - you may need to establish naming standards for tags in your organisation.

## Filter using tags

You can use tags to filter models in the model list, revisions in the model revision history, or activities.

### **Filter model list**

To filter the Model Browser list by tags, hover your mouse over the Tags column until the filter icon appears.

<figure><figcaption></figcaption></figure>

A dropdown menu appears containing all available tags. Select the checkbox next to a tag to activate it as a filter.

<figure><figcaption></figcaption></figure>

When tag filters are active, models are shown in the list if they have **any** selected tag

To clear the filter, click the **x** on the **Clear filters** pill that appears at the top of the list of models when filters are active.

<figure><figcaption></figcaption></figure>

[Click here to find out more about searching and filtering in the Model Browser.](/the-user-interface/models-ui/model-browser)

### **Filter model revisions**

To filter model revisions by tags:

1. Navigate to the Revisions tab in the Model Overview to view the full history of model revisions.
2. Find the tags filter button at on the top-right side of the revisions box.
3. Select the tags filter to open a dropdown of all availavle revision tags.
4. Select the checkbox next to tags you want to use to filter revisions.

<figure><figcaption></figcaption></figure>

Revisions are shown if they have **any** of the selected tags.

### **Filter activities**

You filters lists of activities that appear in the Model Overview or in the main Activities page, which is accessed through the top navigation bar.

For activities in the Model Overview, use the same steps as for filtering model revisions, but start from the Activities tab in Model Overview.

For the main Activities page, select FILTERS at the top-right side of the list of activities, then find tags and select which tags you want to use as filters.
